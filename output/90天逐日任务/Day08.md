## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. 异常列表按 `createdAt` 做 Cursor 分页，两个记录时间相同；翻页同时插入新异常后出现重复和漏项。请保存 SQL、cursor、排序键和两次响应定位；先冻结自动刷新止损，再改为稳定复合排序与不透明游标，并在并发插入 1,000 次时验证集合无重漏。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S2 AgentOps](https://jobs.bytedance.com/experienced/position/7309098238475831562/detail)
2. 攻击者传入 `limit=100000` 和未授权过滤字段，单次查询占满连接池并暴露内部列。请提供 Query DTO 校验、SQL explain、响应字段和连接池证据；先限制 limit 与关闭字段透传，再实现白名单过滤、ViewModel 投影和索引，验证非法输入拒绝且 P95 达标。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S3 阿里 AI 前端](https://campus-talent.alibaba.com/campus/position/199904460001)
知识映射：Cursor 分页、稳定排序、Query DTO、索引草图和 ViewModel。
