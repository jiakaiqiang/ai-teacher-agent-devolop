## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. 同一 anomaly 被并发触发两次，生成两条“有效”Diagnosis；其中一次 ToolCall 已落库但 AgentRun 仍为 `starting`。请用幂等键、事务日志和状态时间线定位；先按 anomaly 锁定新触发止损，再设计唯一约束与事务边界，重复提交 1,000 次验证仅一个有效结果。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S25 PostgreSQL isolation](https://www.postgresql.org/docs/current/transaction-iso.html)
2. 进程在 `Diagnosis` 写入后、`ToolCall` 状态更新前崩溃，重启后 UI 显示完成但工具仍运行。请在四个执行阶段注入 crash，收集 DB 快照与恢复决策；先把不一致 Run 标记待恢复，再实现显式执行状态和补偿/重试，验证每个故障点都有确定终态。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S2 AgentOps](https://jobs.bytedance.com/experienced/position/7309098238475831562/detail)
知识映射：事务、幂等键、执行状态、部分失败和重启恢复。
