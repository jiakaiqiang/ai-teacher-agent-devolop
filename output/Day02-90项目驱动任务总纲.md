# Day 2-90 项目驱动任务总纲

基准：Day 1《AI 前端架构与 Agent 事件模型》  
执行：每天只分发当天详细讲义和任务，本文件用于保证 89 天的知识、项目、架构和岗位能力连续；拆分后的 Day 1-90 文件见[《90 天逐日任务库》](./90天逐日任务/README.md)。  
前端：Day 1-60 使用 Vue 3 + TypeScript，不引入 React。  
项目：Day 2-60 使用 `p1-monitor`；Day 61-90 从零构建 `p2-agent-workbench`，范围见[《项目边界》](./p2-agent-workbench项目边界.md)。

岗位基准：只使用中国大陆市场；当前证据和风险见[《中国 AI 前端与 Agent 岗位动态》](./中国AI前端与Agent岗位动态-2026-07-13.md)。国内官方 JD 决定必修能力，招聘平台只作线索，资源目录的面试 PDF 只用于出题。

## 1. 每日统一标准

Day 2-90 每天都必须包含：

1. 3-5 个知识点讲义：概念、机制、项目落点、误区和验证方法。
2. 一个进入真实项目主链路的纵向增量，不创建独立 Demo。
3. 一个架构证据：合同、状态图、时序图、ADR、Threat Model、性能预算、Eval 或 Runbook。
4. 一个生产失败或原理反证实验。
5. 明确的人机分工：人负责语义、边界、安全、核心状态和最终验收；AI 负责检索、机械骨架、测试候选和 Reviewer。
6. 可量化验收，不使用“基本掌握”“效果不错”等不可复核结论。
7. 每日文件末尾回答 3 道课末核心题、至少 2 道与当天知识点绑定的联网真实项目情境题，以及 2 道资源 PDF 题；完成项目证据后执行教师五连问：局部机制、边界一致性、线上事故、工程权衡、架构演进，其中至少 3 问继续追问当天项目情境。

详细任务在学生发送 `开始 Day N` 时，根据上一日得分和当前代码生成补弱版、标准版或挑战版。

## 8. 顺序与风险控制
