# 90 天 AI 全栈与 Agent 工程师计划

周期：2026-07-14 至 2026-10-11  
投入：工作日每天 3 小时，周末每天 6 小时  
总投入：约 348 小时  
路线：Day 1-60 AI 前端 + AI 全栈，Day 61-90 Agent 工程  
前端约束：前 60 天只使用 Vue 3 + TypeScript，不学习 React；Day 61 后仅评估岗位差距，不把 React 列为毕业条件。

## 1. 目标定义

### Day 1-20：AI 前端可交付

能独立实现流式 AI UI、工具调用、引用、安全、性能与测试，不是只会调用聊天 API。

### Day 21-60：AI 全栈可交付

能完成 Vue 前端、NestJS BFF、Python AI 服务、Postgres/pgvector、Redis、队列、RAG、评测、部署和观测的端到端链路。

### Day 61-90：Agent 工程入门可交付

能从零构建一个规模受控的 Agent 工作台，完成 Tool Runtime、MCP、Context、Memory、Workflow、Eval、Trace、权限与故障恢复。90 天只能达到“Agent 应用/平台转型岗”的求职起点，不能包装成资深 Agent Harness 工程师。

### 全程视角：高级前端架构

90 天所有内容都使用高级前端负责人的视角：从业务领域、系统边界、合同、状态和数据流出发，持续验证性能、安全、可靠性、可观测性、发布和演进成本。后端、RAG 与 Agent 不是孤立教程，而是前端负责人完成端到端 AI 产品交付必须理解的协作边界。执行总纲见[《高级前端架构视角教学总纲》](./高级前端架构视角教学总纲.md)。

## 2. 市场依据

截至 2026-07-13，本计划只用中国大陆市场作为岗位基准。本轮逐页核验了字节跳动 Aime AI 应用前端、字节 AgentOps 前端、阿里云 AI 前端和腾讯 WorkBuddy 智能体全栈四个官方 JD；国内面试 PDF 仅用于设计考题，不用于推断招聘数量。

官方样本交叉出现的要求包括：TypeScript/现代前端工程化、SSE/WebSocket、Agent 任务和工具状态、人工确认/接管、Node/BFF 或后端协作、测试/CI、性能、安全、评测和可观测性。Electron/桌面、本地权限与沙箱、MCP/Skill、Generative UI、AgentOps 是明显增强方向。详细证据、链接、适用边界与 React 风险见[《中国 AI 前端与 Agent 岗位动态》](./中国AI前端与Agent岗位动态-2026-07-13.md)。

因此课程不追逐单一框架，而围绕中国企业当前共同能力：**全链路交付、测试、安全、评测、观测、恢复和可量化结果**。

## 4. 学习纪律

- [《90 天岗位驱动项目课程 v2》](./90天岗位驱动项目课程-v2.md)是当前 13 周、分钟级知识和项目结果的权威路线；[《Day 2-90 项目驱动任务总纲》](./Day02-90项目驱动任务总纲.md)保留为能力连续性基线，[《90 天逐日任务库》](./90天逐日任务/README.md)将其拆成 Day 1-90 独立文件。学生发送 `开始 Day N` 后，教师依据 `12.pdf`、当天知识点、当前项目代码、上一日结果和中国岗位动态，直接分发补弱版、标准版或挑战版任务，不进行课前提问。执行规则见[《每日任务分发协议》](./每日任务分发协议.md)。
- 工作日：40 分钟原理、100 分钟编码、25 分钟测试、15 分钟口述与复盘。
- 周末：1 小时考试、3.5 小时集成、1 小时测试/故障注入、30 分钟文档。
- 每日必须提交：commit、测试输出、3 分钟口述、AI Coding diff 审查记录。
- 每天至少提交一个能对应真实代码的架构证据：状态/时序/C4 局部图、ADR、Schema、Threat Model、性能预算、故障矩阵或发布清单。
- 每日文件末尾先回答 3 道课末核心题、至少 2 道与当天知识点绑定的联网真实项目情境题，以及 2 道资源 PDF 题；项目初步通过后，教师依据真实 diff、测试和日志提出 5 道递进现场题，其中至少 3 道继续追问当天项目情境，五连问通过后才算当天完成。题目证据边界见[《联网调研与真实项目题来源》](./联网调研与真实项目题来源-2026-07-13.md)，执行规则见[《AI 教师五连问验收协议》](./AI教师五连问验收协议.md)。
- 每日 70 分及格；连续两天不及格，停止新增功能并补考。
- Codex/Claude Code 可以辅助，但考试必须关闭 AI 独立完成。

- 简历中的每一个数字均能追溯到测试、日志、报告或代码。

## 13. 严格原则

- 不因会使用 Codex/Claude Code 就提高后端或 Agent 评级。
- 不把“用了很多设计模式”当成架构能力；架构决定必须有约束、备选方案、验证和重审条件。
- 不写“生产级”“完全掌握”“准确率 95%”等未测量结论。
- 不为了使用 LangChain/LangGraph 而使用；先实现最小闭环，再比较框架价值。
- 不展示模型私有 Chain of Thought，只展示可审计步骤与工具摘要。
- React 暂缓不等于永久忽略：Day 89 根据实际投递岗位统计决定后续是否补课。
- 不等待 Day 90 才求职：Day 59（2026-09-10）完成首轮中国目标岗位矩阵并开始投递 AI 前端/AI 应用全栈，Day 89 依据面试反馈校准 Agent 岗位和补课。
- 10 月可投 AI 前端、AI 应用全栈和 Agent 应用/平台转型岗；不直接竞争要求 2-5 年生产 Agent 经验的专家岗。
