前端与 AI 面试资源知识索引

1. 读取范围与方法

  • 已读取 资源 目录全部 58 份 PDF，并单独读取 12.pdf。
  • 总计 59 份 PDF、761 页；资源材料为 757 页，12.pdf 为 4 页。
  • 文本层共提取约 68 万字符，按页保留定位标记。
  • 5 个页面没有文本层。视觉复核确认：
    • 《京东零售前端开发工程师1-3面》P42 是 CSR/SSR 对比表。
    • 《携程前端面试》P3 是 Git 常用命令表。
    • 《2023面试复盘之快手》P8、《小红书前端面经》P9、《腾讯前端面试》P3 为空白页。
  • 频率以“覆盖了多少份 PDF”为主，不以单词出现次数为主，避免题纲和答案重复造成虚高。

2. 资源的四层结构

第一层：前端语言与浏览器底座

必须掌握：HTML 语义化、CSS 盒模型/BFC/Flex/Grid、DOM 事件、JavaScript 类型/作用域/闭包/原型/this、Promise、async/await、Event Loop、TypeScript。

传统资料覆盖率：JS 核心 30/34，HTML/CSS/DOM 29/34，异步机制 23/34，TypeScript 15/34。

建议主材料：

  • 《【精】2024字节前端面试题（45题）》：综合基础，但与无“精”版本高度重复。
  • 《字节跳动与阿里前端面经》：JS、网络、框架、工程化覆盖广。
  • 《百度贴吧 前端研发工程师面经》：长篇综合复习与算法覆盖较全。
  • 《好未来“资深高级前端研发工程师”面经》：异步、浏览器与高级题较集中。
  • 《作业帮前端一面+二面)(vue2+vue3)》：Vue 2/3 专项。

第二层：框架、工程化与高级前端能力

必须掌握：Vue 2/3 响应式、调度、虚拟 DOM、Diff、Vue Router；React Fiber/Hooks；Webpack/Vite、loader/plugin、Tree Shaking、分包；缓存、性能、安全、测试、组件库、微前端、权限和系统设计。

全库覆盖率：Vue 79.3%，React 84.5%，性能 89.7%，工程化 62.1%，安全 81.0%，系统设计 77.6%。这些比例是关键词粗筛结果，用于排序，不代表题目质量。

建议主材料：

  • 《去哪儿网高级前端工程师1-3面》P1-P5：性能指标、RUM/Lab、LCP 分解和场景化设计。
  • 《京东零售前端开发工程师1-3面》：框架与工程化长篇材料；P42 另含 CSR/SSR 图片表。
  • 《钉钉高级前端工程师·面试全流程》P19-P20：高级工程与架构讨论。
  • 《转转集团 前端开发1-3面》：TypeScript、工程化和项目追问。
  • 《【精】京东前端二面面经》：综合题广，但部分答案需校验后再学。

3. 必须形成的唯一答案

不要按公司分别背同一道题。下列题应各维护一个经过验证的“主答案”，不同 PDF 只作为追问来源。

  1. 从输入 URL 到页面显示发生什么。
  2. Event Loop、宏任务、微任务、渲染时机和 Node/浏览器差异。
  3. Promise、async/await、错误传播、取消与并发限制。
  4. 闭包、作用域链、this、原型链和内存管理。
  5. Vue 2/3 响应式、scheduler、虚拟 DOM、Diff、key。
  6. HTTP 缓存、HTTP/1.1/2/3、HTTPS、CORS 与 Cookie 安全。
  7. Webpack loader/plugin、构建流程、Tree Shaking、代码分割。
  8. Core Web Vitals、LCP 四阶段、Lab 与 RUM、P75。
  9. XSS、CSRF、CSP、RBAC/ABAC 和服务端鉴权边界。
  10. SSE、WebSocket、Fetch ReadableStream 的选型与失败恢复。
  11. RAG 的摄取、切分、Embedding、召回、重排、生成和引用链路。
  12. Agent/Function Calling 的工具 Schema、校验、授权、执行、回填与终止。

4. 统一答题评分尺

每题 10 分：

  • 2 分：定义准确，边界清楚。
  • 2 分：执行顺序或端到端数据流完整。
  • 2 分：有关键 API、伪代码或数据结构。
  • 2 分：覆盖异常、安全、成本或性能。
  • 1 分：有可观测指标。
  • 1 分：有真实项目取舍。

只背定义最多 3 分；只罗列名词最多 4 分；没有项目证据不得评为高级答案。

5. 材料质量警告

  • 文件名带公司名不等于官方题库或真实原题，只能作为复习线索。
  • 《2024字节前端面试题（45题）》与《【精】2024字节前端面试题（45题）》内容高度近似，保留后者作为主材料即可。
  • 多份 2026* 资料采用相同模板，闭包、Event Loop、深拷贝、Fiber、SSE 等答案重复，不要重复背诵。
  • 个别答案混淆浏览器与 Node 的任务队列，例如将 process.nextTick 直接列为浏览器微任务。
  • 个别性能答案推荐 HTTP/2 Server Push 作为常规优化，不能照抄；应结合当前基础设施验证。
  • React Fiber 不会自动解决“每个 Token 一次状态更新”，仍需批处理、节流和组件隔离。
  • 前端只能近似估算 Token；最终限制应由服务端和对应模型 tokenizer 判断。
  • Prompt Injection、工具权限和数据鉴权不能依赖前端。
  • 不应向用户展示模型私有 Chain of Thought，只展示可审计的阶段、工具及结果摘要。
  • AI 评测、模型路由、数据治理、Agent 安全和生产事故复盘在现有资源中偏弱，必须另行补课。
