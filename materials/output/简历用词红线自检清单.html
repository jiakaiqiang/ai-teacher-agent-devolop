简历用词红线自检清单

依据 12 号学生严格训练报告 与 当前能力画像。 每次改简历后,逐条对照;任何一条命中,必须改词或补证据后再投。

用法:改完简历后,把这份清单从上到下走一遍。命中 = 有那句话但没证据,或者用了红线词。命中一次判简历不合格,重投前必须改到"证据一栏能填出内容"为止。

A. 事实与文字层(简历必须 100% 通过)

# 红线 命中判定 修法 依据
1 错字:JavsScript / 原项链 / vueRouer / web pack / goole / vibing code 全文搜索出现任一 分别改成 JavaScript / 原型链 / Vue Router / Webpack / Google / vibe coding 报告第 3 节第 1 页 / 第 9 节
2 "包含不仅限于" / "包含不仅限与" 出现 改成"包括但不限于" 报告第 3 节第 1 页
3 "前端微框架 qiankun" 出现 改成"微前端框架 qiankun" 报告第 3 节第 1 页
4 姓名 + 手机号 + 邮箱 + 身份证同时出现在公网/公开投递版 三项全露 公开版脱敏,只对已面试企业发完整版 报告第 3 节第 1 页
5 断成残句的项目描述(项目背景 3 行,读完不知道做了什么) 一眼看不出项目做了什么 用一句"背景 + 目标 + 我做的具体事"重写 报告第 3 节第 2 页

B. "熟练"与"精通"的证据阈值(投递前必须过)

规则:每写一次"熟练"或"精通",必须能承受面试官三轮追问;写不出证据的直接删掉或降级为"使用过"。

断言 触发的追问 你能不能回答 不能回答的处理
熟练掌握 Vue 源码 讲 effect / track / trigger / scheduler / patchFlag / diff 调用关系;ref 与 reactive 的差别与用途;nextTick 内部实现 现在不能(Week 2 会补) 删掉"源码",改为"熟悉 Vue 3 响应式与调度原理,能定位常见响应式失效问题"
熟练 Vue Router 源码 讲路由表 → matcher → history → 导航守卫链路 同上 删掉"源码",改为"熟悉 Vue Router 导航守卫与懒加载"
熟练 Three.js 讲渲染管线、坐标系、拾取、资源释放、LOD、Instancing、帧率治理 3D 机房项目里做过多少?能量化吗? 改为"完成过 3D 机房项目,处理过 X 台设备的渲染优化(fps 从 A 到 B)"
熟练 Webpack / Vite 讲 loader / plugin 生命周期;Tree Shaking 触发条件;persistent cache 如何调优 自定义多语言 Loader 在哪个阶段执行? 能答上一部分才写"熟悉",讲不出细节的改成"具备构建配置调优经验"
熟练 TypeScript(在没有出现在技能栏的时候) 讲泛型约束、条件类型、映射类型、unknown vs any、类型收窄 目前不能稳定回答 技能栏必须加 TypeScript;不能加"熟练",先加"使用"
通过 Vue 实现权限控制 后端资源鉴权在哪?RBAC / ABAC 谁做? 前端只是 UI 权限,后端才是边界 改为"实现基于路由与指令的 UI 权限控制,资源鉴权由后端 RBAC 完成"

C. 性能数字的可信度(数字比嘴强,但必须带口径)

规则:任何百分比、任何"提高 / 减少 / 优化 X%"都必须能立刻答出:分母、样本量、测量工具、测试环境、周期。

红线示例 → 修正后示例:

红线写法 缺什么 修正示例

规则:"用过 Codex / Claude Code" ≠ "AI 工程能力"。凡是写 AI 的地方,必须能给出上下文管理、验证机制、失败恢复三件套。

红线写法 命中判定 修正方向
"智能助手" / "AI 助手" 一笔带过 没说传输、状态、错误、Markdown、上下文 补齐:SSE / Fetch Stream 传输、状态机(idle / running / awaiting-approval / completed / failed / canceled)管理、取消 / 重试 / 幂等、Markdown 增量渲染、Function Calling 前端确认、引用溯源
"大模型分析报表" 没说 RAG、引用、权限、幻觉治理 补齐:RAG 全链路(检索 / 重排 / 生成)、引用溯源、权限过滤、敏感数据脱敏、幻觉治理(格式约束 + 结构化输出 + 二次校验)
"熟练使用 Codex / Claude Code" 只写会用不等于会工程化 改为:"使用 Codex / Claude Code 进行 AI 辅助研发,通过上下文文件 / 任务拆解 / 测试门禁控制生成质量,接受率 X%,人工修改率 Y%"
vibing code 术语错 vibe coding

"AI 全栈"(当前阶段) 后端刚起步 现阶段不写,先写"AI 前端";Day 42 后端专项过关后再评估
