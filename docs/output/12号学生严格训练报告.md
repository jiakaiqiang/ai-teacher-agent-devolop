# `12.pdf` 学生严格训练报告

## 1. 老师结论

这是一份约 7 年经验的前端简历，不是答题卷。学生的真实优势是 Vue 中后台、企业应用交付、工程化迁移、性能专项、ECharts/Three.js、低代码/代码生成，以及有限的 0-1 和组长经验。

当前简历只能证明“做过很多”，还不能稳定证明“为什么这样设计、如何验证、出了问题怎样定位”。按高级前端标准，简历当前评分 **50/100，不及格**。不是经历不够，而是准确性、证据链和知识闭环不够。

岗位匹配度：

| 方向 | 当前匹配度 | 判定 |
|---|---:|---|
| 高级 Vue/企业应用工程化 | 68/100 | 过渡与保底方向 |
| 高级前端通用岗 | 55/100 | 浏览器、TS、测试、安全需补齐 |
| AI 前端 | 38/100 | 目标主投，但必须尽快补 AI 工程作品与证据 |
| 前端架构师/技术专家 | 32/100 | 架构治理、质量体系和影响力未证明 |

短期定位：目标直接对准 AI 前端，但必须用现有 Vue、企业工程化、性能和低代码能力作为转型底座。先把 AI 前端专项做到 70 分，再补齐后端进入 AI 全栈，最后发展到 AI Agent；不要提前使用 AI 全栈或 Agent 工程师头衔。

### 第 2 页：有好素材，但指标和技术决策无证据

### 第 3 页：最有价值，也最容易被问倒

Lighthouse 40 -> 90、FCP 17.6s -> 1.8s、LCP 35.2s -> 2.1s 是最强数据，也是最大风险。

必须准备：相同设备/网络/缓存条件、LCP 元素、LCP 四段耗时、改动清单、每项改动的贡献、实验室数据与 RUM P75 的区别。应写“FCP 缩短至 1.8s”，不是“提高到”。TTFB 如果没有前后数据不要混在成果里。

AI 描述目前不合格：“智能助手”和“大模型分析报表”没有说明 SSE/Fetch Stream、状态机、取消/重试、Markdown 增量渲染、上下文、RAG、Function Calling、权限、引用和评测，不能证明 AI 前端能力。

安全描述也不合格：动态路由和指令只能控制 UI，后端 API 才是权限边界。数据安全项目应补充 XSS/CSRF/CSP、脱敏、审计、租户和资源级权限。

### 第 4 页：技术表述不严谨，版面浪费

- “App 进程杀死做保活”不能承诺永久保活。必须说明前台服务、WorkManager、厂商限制、重启恢复或业务补偿。

- PEG.js 项目必须能讲 grammar、AST/IR、校验、模板层、冲突处理和防止覆盖人工代码。
- 第 4 页下半页大面积空白。7 年简历应压到 2-3 页，只保留 3 个最能证明高级能力的项目。

## 4. 能力缺口与优先级

### A 级：两周内必须补齐

1. 简历全部错字、病句、残句和技术名词。
2. JavaScript：闭包、原型、`this`、Promise、Event Loop、并发控制。
3. 浏览器/网络：URL 到渲染、缓存、HTTP、CORS、XSS/CSRF。
4. Vue：Vue 2/3 响应式、scheduler、Diff、Router、迁移方案。
5. 性能：CWV、LCP 四阶段、Lab/RUM、P75、网络瀑布和长任务。

### B 级：高级岗位必须补齐

1. TypeScript：泛型、类型收窄、条件/映射类型、API 类型设计。
2. 测试：单测、组件测试、E2E、视觉回归和迁移回归。
3. 工程治理：包发布、语义化版本、CI/CD、监控、灰度、回滚。
4. 安全与权限：CSP、Cookie、RBAC/ABAC、服务端资源鉴权、租户隔离。
5. 架构表达：备选方案、权衡、失败策略、可观测性和复盘。

### C 级：投 AI 前端前必须补齐

1. SSE、WebSocket、Fetch `ReadableStream` 的选型。
2. `TextDecoder(stream: true)`、跨 chunk 缓冲、取消、重试和幂等。
3. 流式 Markdown/代码块/公式、节流更新、历史消息虚拟化。
4. RAG 全链路、引用溯源、权限过滤和幻觉治理。
5. Agent/Function Calling、工具 Schema、状态机、人工确认和审计。
6. TTFT、TPS、中断率、任务完成率、成本和离线评测集。

## 5. 六周训练计划

每天最低 2 小时：45 分钟原理、45 分钟编码、30 分钟口述。禁止只看答案不输出。

### 第 1 周：JavaScript 与浏览器硬基础

- 学：作用域/闭包/原型/`this`、Promise、Event Loop、URL 到渲染、HTTP 缓存。
- 写：`debounce`、`Promise.all`、并发 Scheduler、深拷贝。
- 讲：每题录制 3 分钟回答，必须包含边界和项目例子。
- 过关：随机 10 题平均 7/10；4 道手写题 45 分钟内完成并覆盖边界。

### 第 2 周：Vue、TypeScript 与迁移

- 学：Vue 2/3 响应式、scheduler、虚拟 DOM、Diff、Vue Router；TS 泛型与类型设计。
- 做：写一个最小响应式系统；整理 Vue2 -> Vue3 依赖迁移矩阵、灰度、回滚和测试方案。
- 过关：白板讲清 `track -> trigger -> queueJob -> flush`；迁移方案能回答三轮“为什么”。

### 第 3 周：工程化、质量与性能

- 学：Webpack/Vite、loader/plugin、Tree Shaking、组件库版本、CI、测试、CWV、RUM。
- 做：用真实项目生成 bundle 报告；记录冷缓存下 5 次测试；拆解 LCP 四阶段。
- 交付：一份可审计的性能报告，包含环境、基线、改动、结果和限制。
- 过关：任何百分比都能说出分母、样本、环境和工具。

### 第 4 周：架构、安全与特色项目

- 学：微前端、npm 私包 vs submodule vs monorepo、RBAC/ABAC、XSS/CSRF/CSP、插件 SDK。
- 做：为组件库、PEG 代码生成器、3D SDK 各画一张架构图并写 ADR。
- 过关：每个方案至少比较两个替代方案；能讲失败与回滚。

### 第 5 周：AI 前端闭环

- 做一个可演示应用：POST 流式请求、取消、重试、增量 Markdown、代码高亮、会话列表、错误状态。
- 加入 RAG 引用展示和一次工具调用；工具执行前做参数校验和用户确认。
- 采集 TTFT、完成耗时、中断率、错误率和 Token/成本估算。
- 过关：断网、半包、未闭合代码块、重复事件、用户取消、XSS 输出六类测试全部通过。

### 第 6 周：项目防守与模拟面试

- 将机器人平台、代码生成器、数据安全审计压成三个 STAR+ADR 案例。
- 每个案例准备 1 分钟、3 分钟、8 分钟三个版本。
- 完成 3 次 60 分钟模拟：基础、项目深挖、架构/AI。
- 过关：总分 >= 70；任何简历数字均可展示证据；连续三轮追问不自相矛盾。

## 6. 个性化必答题

以下问题不允许背一句话答案。每题按 10 分尺评分，低于 7 分必须重做。

1. Vue2 到 Vue3 的依赖清单、兼容策略、灰度和回滚如何设计？
2. Vue3 响应式、scheduler、模板编译、Patch Flags 与 Diff 如何协作？
3. Vue Router 从路由表、matcher、history 到导航守卫的执行链是什么？
4. 49.7 MB 到 35.2 MB 测的是什么？gzip/Brotli 后体积和首屏请求量是多少？
5. LCP 元素是什么？35.2s 的四段耗时分别是多少？为什么能降到 2.1s？
6. Lighthouse 是否同设备、同网络、冷缓存？有没有真实用户 P75 数据？
7. 自定义多语言 Loader 在哪个构建阶段执行？如何提取、去重和处理动态文本？
8. Git submodule 为什么优于 npm 私包或 monorepo？版本和回滚怎么做？
9. 组件库有多少组件、几个团队使用？怎样做单测、视觉回归和 Breaking Change？
10. PEG.js 的 grammar、AST/IR、模板层如何分离？怎样避免覆盖人工修改？
11. 3D 平台怎样处理坐标系、拾取、资源释放、LOD 和 Instancing？
12. 大数据下拉到底多少条？为什么用滚动加载，不用虚拟列表？
13. 动态路由和指令为何不能防越权？后端怎样做资源级鉴权？
14. AI 助手用 SSE、WebSocket 还是 Fetch Stream？为什么？
15. 流式 Markdown 遇到跨 chunk UTF-8 和未闭合代码块怎样处理？
16. 报表大模型是否使用 RAG？引用、权限、幻觉和敏感数据怎样治理？
17. SDK 插件协议、生命周期、异常隔离和版本兼容怎样设计？
18. Android“保活”的系统版本、具体机制、限制和合规边界是什么？
19. 组长带几人？怎样估算任务、Code Review、处理延期和质量事故？
20. 讲一个失败案例：第一版哪里错了，使用什么数据纠正？
