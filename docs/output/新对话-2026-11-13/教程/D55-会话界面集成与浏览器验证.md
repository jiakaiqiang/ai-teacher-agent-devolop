## 一、知识点与推导

### 1.1 集成层负责用户意图

ConversationPanel把send/fork/select/stop映射到原生表单和按钮；数据由useConversation管理。编辑旧问题创建兄弟分支，原路径仍能回看。busy时禁止重复发送和分支切换。

**推导题：组件为何不直接拼接流数据？**

<details><summary>答案</summary>

拼接、身份、终态和指标已有独立契约；把它们复制进模板会产生两套状态规则。

</details>

### 1.2 可解释的状态与焦点

面板区分模拟/模型、完整/截断/停止/中断/失败。停止后焦点回问题输入框，下一Tab到发送；状态live region只读短状态，不逐字播报整段回答。输入有label和提示关联，编辑不覆盖旧历史。

**推导题：看到completed能相信答案吗？**

<details><summary>答案</summary>

只能说明应用流完整结束；建议仍需人工核实。模拟卡片完成也不等于真实工具执行。

</details>

### 1.3 测试按能证明的范围分层

SSR检查标签、转义和语义；组合函数测试检查异步归属；Chromium验证真实DOM、滚动和焦点。响应夹具能可靠触发length/EOF/timeout事件/503，但不能证明真实供应商行为。

**推导题：一个绿色截图能证明取消链路吗？**

<details><summary>答案</summary>

不能。需要状态、请求取消与后续回调隔离证据；本章UI验证与D51单元、W7服务端取消测试互相补充。

</details>

### 1.4 长列表验收必须测几何

真实VirtualConversation挂200行合成数据，记录实际挂载行数、锚点ID/偏移、回到底部间距、焦点保留和显示全部。合成行高度变化用于重现上方增高；不把减少DOM数量说成已测FPS改善。

**推导题：为什么还要显示全部？**

<details><summary>答案</summary>

虚拟行不在DOM时，浏览器查找与辅助阅读受限；有界200行下提供明确的完整展示路径。

</details>

<script setup lang="ts">
import {computed,nextTick,ref,watch} from 'vue'
import {useConversation} from '../composables/useConversation'
import {isGenerating,type GenerationStatus} from '../assistant/generation'
import {metricsView,summarizeMetrics} from '../assistant/metrics'
import SafeMarkdown from './SafeMarkdown.vue'
import AssistantCards from './AssistantCards.vue'
import VirtualConversation from './VirtualConversation.vue'
const props=defineProps<{ticketNo:string}>()
const {turns,path,activeLeaf,busy,error,send,fork,select,stop}=useConversation(()=>props.ticketNo)
const question=ref('请给出这张模拟工单的排查步骤');const editId=ref<string|null>(null);const input=ref<HTMLTextAreaElement>()
const labels:Record<GenerationStatus,string>={connecting:'正在连接',streaming:'正在生成',completed:'生成完成',truncated:'达到长度限制，内容不完整',stopped:'已停止，保留部分内容',interrupted:'生成中断，保留部分内容',error:'生成失败'}
const last=computed(()=>path.value.at(-1));const summary=computed(()=>summarizeMetrics(turns.value.map(turn=>turn.metrics)))
watch(()=>props.ticketNo,()=>{question.value='请给出这张模拟工单的排查步骤';editId.value=null},{flush:'sync'})

async function stopAndFocus(){stop();await nextTick();input.value?.focus()}
function changeBranch(event:Event){select((event.target as HTMLSelectElement).value);editId.value=null}
const number=(value:number|null)=>value===null?'暂无':value.toFixed(1)
</script>

<script setup lang="ts">
import { ref, watch } from 'vue'
import ConversationPanel from '../components/ConversationPanel.vue'
import TicketFeedback from '../components/TicketFeedback.vue'
import { useRoute } from 'vue-router'

## 五、核心面试题

1. 编辑历史问题为什么不直接修改数组？ 要点：修改旧节点会改变原回答的上下文含义，也可能破坏已有后代。本章保留原节点，以原parentId创建兄弟分支，activeLeaf决定展示路径。追问：刷新后还在吗？不在，本周只存页面内存，UI必须明确。
2. 停止后的焦点和状态如何处理？ 要点：立即取消本机等待，保留部分内容并标记stopped；焦点回输入，用户可键盘发起下一次。状态live region只播短状态，不每个token打断读屏。追问：等于所有辅助技术都验收了吗？没有，真实读屏器仍未测。
3. 如何区分三类浏览器证据？ 要点：真实本机模拟流证明前后端与UI集成；响应夹具证明特定错误的展示；200行合成数据证明组件几何和交互。三者均不能替代真实供应商、低端设备和线上长时间性能。追问：测了挂载8行能说快多少？不能，没有时延/帧率对照。
