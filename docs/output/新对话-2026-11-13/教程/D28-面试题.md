# D28 模拟面试：第四周

## 新版工单口述与自检

以两家客户的待办统计口述缓存一致性、互斥锁、限流，引用一条实验输出。

新版练习按[本日讲义](D28-第四周复盘.md)的操作与验收结果作答。

## 技术题及出处

以下题库保留来源中的场景，历史实验的数字仅对应原课程。

配套讲义：[D28：第四周复盘](D28-第四周复盘.md)。今天不引入新题，从 D22-D27 的面试题里挑出 8 道，按真实面试的方式练：先口述，再接追问，最后对照答案打分。

每道题后面的“答案在哪”指向原来的面试题文件或讲义，那里有原题出处、原文答案和完整的参考答案。

## 规则

1. 每题限时 3 分钟口述，不看资料。追问每个限时 1 分钟。
2. 每题都要包含一个你在这个项目里亲手做过的例子，最好带上一个测出来的数字或现象。
3. 这一周的题按“这个机制解决什么问题 → 我怎么实现的 → 去掉它会怎样（反证实验或实测数字）”的顺序讲。
4. 全部说完再对照答案，按末尾的评分表打分。
