## 一、知识点与推导（35分钟）

### 1.1 postJson不能读取流

原http.ts先response.json()再校验包裹data，适用于一次性JSON。助手需要POST body和JWT头，响应是持续SSE，因此单独streamAssistant，不改所有JSON请求。ticketNo先encodeURIComponent，问题只放body，供应商密钥从不进前端。

读取顺序是HTTP状态→媒体类型/body→D44 readSse→JSON→assistantEventSchema→首帧/事件名检查→回调。没有meta先来delta、重复meta、event与type不一致都拒绝。只在done/error终止后成功返回；EOF没有终止则抛STREAM_INTERRUPTED。

**推导题**：收到200 HTML代理页，能让用户看到它吗？

<details><summary>答案</summary>

不能当模型文本，媒体类型不符为CONTRACT_MISMATCH。上游错误文本可能含内部信息，界面只显示预设消息。

</details>

### 1.2 一次生成的状态足够清晰，不提前做多轮会话

| 状态 | 触发 | 保留文字 |
|---|---|---|
| idle | 初始化/reset/身份变化 | 清空 |
| connecting | 请求已发，未有正文 | 新请求开始清空 |
| streaming | 收到delta | 追加 |
| completed | done.stop | 保留 |
| truncated | done.length | 保留，明确长度限制 |
| stopped | 用户主动停止 | 保留 |
| interrupted | 有部分正文后错误/断流 | 保留 |
| error | 没有正文的失败 | 无可展示正文 |

busy只由connecting/streaming推导，禁止重复提交。transport返回后若还busy，说明未收到合法终止，不能把finally当成功回调。最终错误展示固定中文，不透传异常message。

**推导题**：停止后应该清空答案吗？

<details><summary>答案</summary>

本章规则是保留已收到部分并显示stopped；切工单/切身份或新请求才reset。停止不意味着下次可从原位置续接。

</details>

### 1.3 abort负责取消，序号负责结果归属

旧请求可能已经排好了回调，或注入transport根本不合作取消。因此每次回调、catch和finally都检查：未dispose、id仍为sequence、token仍是当前会话。停止/reset先递增sequence再abort，使旧回调立刻失效。

```text
请求A开始(id=1) → 收到部分 → 停止(sequence=2)
请求B开始(id=3) → A迟到delta(id=1) → 丢弃
```

序号不是业务幂等键，不会取消供应商计费。它保护前端状态归属，和D46取消链路配合使用。用同一用户连续两次请求也要序号，不能仅比较token。

**推导题**：旧请求finally把controller设undefined，会影响新请求吗？

<details><summary>答案</summary>

会，可能失去取消新请求的句柄。所以finally同样检查current，不能只保护delta回调。

</details>

### 1.4 身份边界也是异步边界

watch accessToken使用flush:sync，切会话即清空、取消；dispose清watch。401处理捕获请求开始时token，只在它仍等于session当前token时注销，防止旧alice请求返回401却注销新bob会话。

本章401不解析服务器业务body，统一提示重新登录；404/403分别固定提示，其他HTTP错误不透传原始内容。没有自动重试或历史存储，D48负责工单路由变化时reset与卸载dispose。

**推导题**：token相同，但工单路由变了，今天模块会自动知道吗？

<details><summary>答案</summary>

不会，它只接start参数。页面必须在ticketNo变化时调用reset；D48把这个生命周期接上，不能把模块测试当已完成页面集成。

</details>

**apps/web/src/api/assistant.ts**

```ts
import { assistantEventSchema, readSse, type AssistantEvent } from '@ops-ticket/shared'
import { handleUnauthorized, session } from './session'

export class AssistantError extends Error {}
// 单次POST不自动重试；只有应用终止事件才能完成。
export async function streamAssistant(ticketNo: string, question: string, token: string,
  signal: AbortSignal, receive: (event: AssistantEvent) => void): Promise<void> {
  const response = await fetch(`/api/tickets/${encodeURIComponent(ticketNo)}/assistant`, {
    method: 'POST', headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json', Accept: 'text/event-stream' },
    body: JSON.stringify({ question }), signal,
  })
  if (!response.ok) {
    await response.body?.cancel()
    if (response.status === 401 && token === session.value?.accessToken) handleUnauthorized()
    throw new AssistantError(response.status === 401 ? 'UNAUTHENTICATED' : response.status === 404 ? 'NOT_FOUND' : response.status === 403 ? 'FORBIDDEN' : 'HTTP_ERROR')
  }
  if (!response.headers.get('content-type')?.startsWith('text/event-stream') || !response.body) {
    await response.body?.cancel(); throw new AssistantError('CONTRACT_MISMATCH')
  }
  let meta = false; let chars = 0
  for await (const frame of readSse(response.body, { signal })) {
    let value: unknown
    try { value = JSON.parse(frame.data) as unknown } catch { throw new AssistantError('CONTRACT_MISMATCH') }
    const parsed = assistantEventSchema.safeParse(value)
    if (!parsed.success || frame.event !== parsed.data.type) throw new AssistantError('CONTRACT_MISMATCH')
    const event = parsed.data
    if (event.type === 'meta') {
      if (meta) throw new AssistantError('CONTRACT_MISMATCH')
      meta = true
    } else if (!meta) throw new AssistantError('CONTRACT_MISMATCH')
    if (event.type === 'delta') {
      chars += event.text.length
      if (chars > 32_768) throw new AssistantError('OUTPUT_LIMIT')
    }
    receive(event)
    if (event.type === 'done' || event.type === 'error') return
  }
  throw new AssistantError('STREAM_INTERRUPTED')
}
```

**apps/web/src/composables/useAssistant.ts**

```ts
import { computed, ref, watch } from 'vue'
import { session } from '../api/session'
import { streamAssistant } from '../api/assistant'

export type AssistantStatus = 'idle' | 'connecting' | 'streaming' | 'completed' | 'truncated' | 'stopped' | 'interrupted' | 'error'
type Transport = typeof streamAssistant
const messages: Record<string, string> = {
  MODEL_TIMEOUT: '生成超时，已保留收到的内容', MODEL_CANCELLED: '服务已停止生成，已保留收到的内容',
  MODEL_UNAVAILABLE: '排查建议暂不可用', NOT_FOUND: '工单不存在或不可见', FORBIDDEN: '没有查看权限', UNAUTHENTICATED: '请重新登录',
}
export function useAssistant(transport: Transport = streamAssistant) {
  const text = ref(''); const status = ref<AssistantStatus>('idle'); const mode = ref<'mock' | 'model' | null>(null); const error = ref('')
  const busy = computed(() => status.value === 'connecting' || status.value === 'streaming')
  let sequence = 0; let controller: AbortController | undefined; let disposed = false
  const invalidate = () => { sequence++; controller?.abort(); controller = undefined }
  const reset = () => { invalidate(); text.value = ''; status.value = 'idle'; mode.value = null; error.value = '' }
  const stopWatch = watch(() => session.value?.accessToken, reset, { flush: 'sync' })
  async function start(ticketNo: string, question: string): Promise<void> {
    if (disposed || busy.value) return
    const token = session.value?.accessToken
    if (!token || !question.trim() || question.trim().length > 1000) { status.value = 'error'; error.value = token ? '请输入1—1000字的问题' : '请重新登录'; return }
    reset(); const id = sequence; const abort = new AbortController(); controller = abort
    const current = () => !disposed && id === sequence && token === session.value?.accessToken
    status.value = 'connecting'
    try {
      await transport(ticketNo, question.trim(), token, abort.signal, (event) => {
        if (!current()) return
        if (event.type === 'meta') mode.value = event.mode
        if (event.type === 'delta') { text.value += event.text; status.value = 'streaming' }
        if (event.type === 'done') status.value = event.finishReason === 'length' ? 'truncated' : 'completed'
        if (event.type === 'error') { status.value = text.value ? 'interrupted' : 'error'; error.value = messages[event.code] ?? '生成中断，已保留收到的内容' }
      })
      if (current() && busy.value) { status.value = text.value ? 'interrupted' : 'error'; error.value = '连接结束，未收到完成事件' }
    } catch (cause) {
      if (current()) { status.value = text.value ? 'interrupted' : 'error'; error.value = messages[cause instanceof Error ? cause.message : ''] ?? '生成中断，请检查连接后重新尝试' }
    } finally { if (current()) controller = undefined }
  }
  function stop() { if (!busy.value) return; invalidate(); status.value = 'stopped'; error.value = '' }
  function dispose() { if (disposed) return; reset(); disposed = true; stopWatch() }
  return { text, status, mode, error, busy, start, stop, reset, dispose }
}
```

## 六、个人建议

你熟悉Vue组合式函数，今天的新难点是异步归属与结果语义。不要把所有状态压成loading和error两个变量；口述一次A停止、B启动、A迟到的时间线，比背“防抖节流”更贴近实际AI交互。
