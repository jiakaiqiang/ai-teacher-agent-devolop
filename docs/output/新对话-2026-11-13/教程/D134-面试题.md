# D134 面试题　按来源组装诊断上下文

## 题库原题与原文答案

本地《2026京东前端面试-大模型方向.pdf》，第 7 页。

<details><summary>原题与答案原文</summary>

4. 什么是 RAG（检索增强生成）？前端在 RAG 流程中可以做哪些工作？​
难度：★★★
考点：RAG 架构、AI 业务场景​
答案要点：
RAG 通过检索外部知识库来弥补模型训练数据的时效性问题，前端主要负责交互展示和元数据反馈。​
•
引用溯源：展示模型回答所依据的文档片段，并支持点击跳转到原文档具体位置
•
检索反馈：允许用户对检索到的内容进行“准确/不准确”的点赞踩，用于优化 Embedding 质量​
•
文档处理：在上传知识库阶段，前端可以进行文件预处理、分段预览以及元数据编辑
•
状态可视化：展示检索中、思考中、生成中等细分状态，缓解用户等待焦虑
常见坑：
•
溯源链接失效或定位不准
•
忽略了检索到的敏感信息在前端的脱敏处理
追问：
•
如何在前端实现 PDF 文档的关键词高亮定位？​

</details>

把检索链路图补到模型入口。前端可以展示来源，后端负责分角色组装、检查权限和限制动作。



## 项目面试与自检

### 1. 同一条建议和用户说“没效果”应怎样进入上下文？

分别标为建议与验证结果，保留先后关系和出处。

### 2. 工单版本正确是否足以保证外部操作只执行一次？

外部接收方还需按同一幂等键认领并保存结果。

### 3. 发送方没有回执能否推断接收方没有执行？

到接收端查幂等记录，返回第一次结果，分别记录发送次数和实际执行次数。
