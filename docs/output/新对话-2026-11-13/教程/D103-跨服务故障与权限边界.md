## 一、知识点与推导

示例按语法树从当天通过的测试提取。保留完整文件中的导入和辅助函数，使用所列命令运行，不要只复制函数体。

### 1.1 请求体字节上限要自己加

D99的契约限制的是**码点**（16条、每条2048个），不是字节。一个请求可以在解析前就很大：600KB的垃圾JSON仍会被完整读入内存再报422。FastAPI/Starlette没有内置的请求体上限（Nginx有`client_max_body_size`，默认1MB，但本章不依赖反向代理）。`BodyLimit`是一个ASGI中间件，放在最外层：有`Content-Length`且超限（或不是数字）直接413；没有`Content-Length`（分块传输）就按实际收到的字节累计，超限立即413并停止读取。上限取512KiB，依据是最大合法请求的实测大小：16条×2048个表情字符，JSON默认`ensure_ascii`转义后每个表情12字节，约393KB（这个数就是测试里断言的`390_000 < len(body) <= MAX_BODY`；最初按4字节估成256KiB，被这条测试直接否掉了）。

**可运行示例：test_largest_legal_request_fits_the_limit**

来源：`python/bridge/tests/test_limits.py`。

**推导题：为什么不能只看`Content-Length`？**

<details><summary>答案</summary>

分块传输（`Transfer-Encoding: chunked`）没有这个头，声明值也可能与实际不符。必须按实际读到的字节累计才有效，本章用真实的分块请求验证了这一点。

</details>

### 1.2 错误体只有一种形状

D99的422、D100的502/504、D101的502已经是`{"error":{"code":...}}`。本章把剩下两处补齐：401原来由`HTTPException`产生，响应体是`{"detail":...}`，改成自定义异常加处理器，统一成固定码`BRIDGE_UNAUTHORIZED`；再加一个`Exception`兜底处理器，任何未预期异常都返回500 `BRIDGE_INTERNAL`，不带类型名、消息和堆栈。调用方只需要解析一种结构，这也是NestJS侧能把码直接转成`BRIDGE_<码>`的前提。注意兜底处理器不会吞掉问题：异常仍会记录在服务日志里，只是不回给调用方。

**可运行示例：test_chunked_body_is_counted_without_content_length**

来源：`python/bridge/tests/test_limits.py`。

```python
def test_chunked_body_is_counted_without_content_length() -> None:
    def stream() -> Iterator[bytes]:
        for _ in range(MAX_BODY // 4096 + 2):
            yield b" " * 4096

    with client() as http:
        result = http.post(URL, headers=HEADERS, content=stream())
    assert result.request.headers.get("transfer-encoding") == "chunked"
    assert "content-length" not in result.request.headers
    assert result.status_code == 413
```

**推导题：统一错误体之后，调用方怎么区分“我发错了”和“对方坏了”？**

<details><summary>答案</summary>

看HTTP状态：4xx是调用方的问题（422入参、401令牌、413过大），5xx是服务端或上游（502上游失败、504上游超时、500未预期）。码只用来定位具体原因。

</details>

### 1.3 依赖停止时抛的不是你以为的异常

D101把`MilvusException`映射成固定码。本章实测：**Milvus容器停止时抛的是`grpc.aio._call.AioRpcError`**，继承链是`grpc.RpcError → Exception`，与`MilvusException`无关，2.03秒返回。第一次故障注入因此得到500 `BRIDGE_HTTP_500`（原始记录保留为`bridge-faults.log.history1`）。修正：`VectorStore._call`再捕获`grpc.RpcError`，映射成`MILVUS_UNAVAILABLE`（502）。教训是：映射依赖库的异常前，先把依赖真的停掉看一次，不要只按文档的异常类型写。

**推导题：为什么不直接捕获`Exception`来省事？**

<details><summary>答案</summary>

那会把自己代码里的bug（例如字段名写错导致的KeyError）也当成“上游不可用”，掩盖真正的问题。兜底处理器返回500正是为了把这两类区分开。

</details>

### 1.4 恢复不需要重启桥接服务

故障注入的后半段：停掉Ollama后请求得到`BRIDGE_EMBED_UNAVAILABLE`（约2秒）；重新启动Ollama后，**同一个桥接进程**直接恢复成功，因为httpx2的连接池会为新请求建立新连接。停掉Milvus得到`BRIDGE_MILVUS_UNAVAILABLE`（约2.1秒），Milvus恢复后同一进程立即成功，5秒后再测仍成功——gRPC通道会自己重连。这说明进程级复用客户端（D100、D101的做法）不会在依赖重启后留下坏连接。但要注意这只验证了“依赖重启”，没有验证网络分区、半开连接和长时间空闲。

**apps/server/src/retrieval/bridge.ts**

```ts
import { z } from 'zod';
import { space } from './encoding.js';

export interface BridgeConfig { base: string; token: string; }
export type BridgeCandidate = { sourceKey: string; version: string; start: number; end: number; distance: number };
export type BridgeRow = { sourceKey: string; groupId: string; version: string; start: number; end: number; text: string };

// 只允许回环地址；令牌只读环境变量，不写日志、不进错误信息。
export function readBridgeConfig(env: NodeJS.ProcessEnv = process.env): BridgeConfig {
  const token = env.OPS_BRIDGE_TOKEN?.trim() ?? '';
  if (token.length < 32 || !/^[\x21-\x7e]+$/.test(token)) throw new Error('BRIDGE_CONFIG');
  let url: URL;
  try { url = new URL(env.OPS_BRIDGE_URL?.trim() || 'http://127.0.0.1:8090'); } catch { throw new Error('BRIDGE_CONFIG'); }
  if (url.protocol !== 'http:' || !['127.0.0.1', '[::1]'].includes(url.hostname) ||
      url.username || url.password || url.search || url.hash || url.pathname !== '/') throw new Error('BRIDGE_CONFIG');
  return { base: url.origin, token };
}

const failure = z.object({ error: z.object({ code: z.string().regex(/^[A-Z0-9_]{1,40}$/) }) });
const candidates = z.object({ schema_version: z.literal(1), space: z.literal(space), candidates: z.array(z.object({
  source_key: z.string(), version: z.string(), start: z.number().int().nonnegative(),
  end: z.number().int().positive(), distance: z.number().finite() }).strict()).max(24) }).strict();
const written = z.object({ written: z.number().int().nonnegative() }).strict();

// 外层35秒：Python内部编码20秒加Milvus10秒，外层必须更长，避免这里先放弃而对方仍在占用模型。
export async function bridgeCall(path: string, body: unknown, config = readBridgeConfig(), request: typeof fetch = fetch,
  timeoutMs = 35000) {
  let response: Response;
  try {
    response = await request(config.base + path, {
      method: 'POST', redirect: 'error', signal: AbortSignal.timeout(timeoutMs),
      headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + config.token },
      body: JSON.stringify(body),
    });
  } catch (error) {
    // 连不上、连接被重置、超时都在这里；原始错误里可能带地址，只保留固定码。
    throw new Error(error instanceof Error && error.name === 'TimeoutError' ? 'BRIDGE_TIMEOUT' : 'BRIDGE_UNAVAILABLE');
  }
  const reply: unknown = await response.json().catch(() => null);
  if (!response.ok) {
    const parsed = failure.safeParse(reply);
    const code = parsed.success ? parsed.data.error.code : 'HTTP_' + response.status;
    throw new Error(code.startsWith('BRIDGE_') ? code : 'BRIDGE_' + code);
  }
  return reply;
}

export async function bridgeSearch(query: string, groupId: string | null, call = bridgeCall): Promise<BridgeCandidate[]> {
  const reply = candidates.safeParse(await call('/v1/chunks/search', { query, group_id: groupId, limit: 24 }));
  if (!reply.success) throw new Error('BRIDGE_CONTRACT');
  return reply.data.candidates.map(c => ({ sourceKey: c.source_key, version: c.version, start: c.start, end: c.end, distance: c.distance }));
}

export async function bridgeUpsert(rows: BridgeRow[], call = bridgeCall) {
  const reply = written.safeParse(await call('/v1/chunks/upsert', { rows: rows.map(r => ({
    source_key: r.sourceKey, group_id: r.groupId, version: r.version, start: r.start, end: r.end, text: r.text })) }));
  if (!reply.success || reply.data.written !== rows.length) throw new Error('BRIDGE_CONTRACT');
  return reply.data.written;
}

export function retrievalBackend(env: NodeJS.ProcessEnv = process.env): 'node' | 'python' {
  const value = env.RETRIEVAL_BACKEND?.trim() || 'node';
  if (value !== 'node' && value !== 'python') throw new Error('RETRIEVAL_BACKEND');
  return value;
```

```python
"""只供回环访问的服务入口；业务路由要求独立服务令牌。"""
import os
from collections.abc import AsyncIterator, Callable
from contextlib import asynccontextmanager
from hmac import compare_digest
from typing import Annotated

import httpx2
from fastapi import Depends, FastAPI, Header, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse

from ops_bridge.embedding import EmbeddingClient, EmbeddingError, local_client
from ops_bridge.http_contracts import (
    CandidateOut,
    ChunkSearch,
    ChunkUpsert,
    EmbedPlan,
    EmbedRequest,
    EmbedResult,
    SearchResult,
)
from ops_bridge.limits import BodyLimit
from ops_bridge.vector_store import ChunkRow, VectorStore, VectorStoreError, milvus_store


class Unauthorized(Exception):
    pass


def create_app(token: str,
               make_client: Callable[[], httpx2.AsyncClient] = local_client,
               make_store: Callable[[], VectorStore] = milvus_store) -> FastAPI:
    if len(token) < 32 or not token.isascii():
        raise ValueError("OPS_BRIDGE_TOKEN必须为至少32字符的ASCII随机令牌")

    @asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        # 整个进程复用一个连接池；退出时关闭，不留悬挂连接。
        async with make_client() as client:
            app.state.embedder = EmbeddingClient(client)
            store = make_store()
            app.state.store = store
            try:
                yield
            finally:
                await store.close()

    app = FastAPI(title="本机检索桥接", version="1.0.0", docs_url=None, redoc_url=None,
                  lifespan=lifespan)

    async def authenticate(authorization: Annotated[str | None, Header()] = None) -> None:
        if not compare_digest((authorization or "").encode(), ("Bearer " + token).encode()):
            raise Unauthorized

    # 最外层先限制请求体字节数，超限直接413，不进入JSON解析。
    app.add_middleware(BodyLimit)

    @app.exception_handler(Unauthorized)
    async def unauthorized(request: Request, error: Unauthorized) -> JSONResponse:
        # 与其他失败同一结构，调用方只需解析一种错误体。
        return JSONResponse(status_code=401, content={"error": {"code": "BRIDGE_UNAUTHORIZED"}})

    @app.exception_handler(RequestValidationError)
    async def invalid_input(request: Request, error: RequestValidationError) -> JSONResponse:
        # 不回显错误输入或请求头；诊断信息由独立测试保留。
        return JSONResponse(status_code=422, content={"error": {"code": "BRIDGE_INPUT"}})

    @app.exception_handler(EmbeddingError)
    async def upstream_failed(request: Request, error: EmbeddingError) -> JSONResponse:
        # 上游超时504，其余上游问题502；只返回固定码。
        status = 504 if error.code == "EMBED_TIMEOUT" else 502
        return JSONResponse(status_code=status, content={"error": {"code": error.code}})

    @app.exception_handler(VectorStoreError)
    async def store_failed(request: Request, error: VectorStoreError) -> JSONResponse:
        status = 504 if error.code == "MILVUS_TIMEOUT" else 502
        return JSONResponse(status_code=status, content={"error": {"code": error.code}})

    @app.exception_handler(Exception)
    async def unexpected(request: Request, error: Exception) -> JSONResponse:
        # 兜底：未预期的异常也只返回固定码，不带类型名、消息或堆栈。
        return JSONResponse(status_code=500, content={"error": {"code": "BRIDGE_INTERNAL"}})

    @app.get("/healthz")
    async def health() -> dict[str, str]:
        return {"status": "ok"}

    @app.post("/v1/embedding/validate", response_model=EmbedPlan,
              dependencies=[Depends(authenticate)])
    async def validate(body: EmbedRequest) -> EmbedPlan:
        # 只确认契约，不生成向量。
        return EmbedPlan(count=len(body.texts))

    @app.post("/v1/embedding", response_model=EmbedResult,
              dependencies=[Depends(authenticate)])
    async def embed(body: EmbedRequest, request: Request) -> EmbedResult:
        embedder: EmbeddingClient = request.app.state.embedder
        vectors = await embedder.encode(body.texts, body.role)
        return EmbedResult(count=len(vectors), vectors=[list(v) for v in vectors])

    @app.post("/v1/chunks/upsert", dependencies=[Depends(authenticate)])
    async def upsert(body: ChunkUpsert, request: Request) -> dict[str, int]:
        # 只写坐标、版本与向量；正文不进Milvus，读侧回权威库取原文。
        vectors = await request.app.state.embedder.encode([r.text for r in body.rows], "passage")
        rows = [ChunkRow(r.source_key, r.group_id, r.version, r.start, r.end, vector)
                for r, vector in zip(body.rows, vectors, strict=True)]
        store: VectorStore = request.app.state.store
        return {"written": await store.upsert(rows)}

    @app.post("/v1/chunks/search", response_model=SearchResult,
              dependencies=[Depends(authenticate)])
    async def search(body: ChunkSearch, request: Request) -> SearchResult:
        # 返回的只是候选；权限、状态与版本由NestJS在权威库复核。
        (vector,) = await request.app.state.embedder.encode([body.query], "query")
        store: VectorStore = request.app.state.store
        hits = await store.search(vector, body.group_id, body.limit)
        return SearchResult(candidates=[CandidateOut(source_key=h.source_key, version=h.version,
                                                     start=h.start, end=h.end,
                                                     distance=h.distance) for h in hits])

    return app


def from_environment() -> FastAPI:
    return create_app(os.environ.get("OPS_BRIDGE_TOKEN", ""))
```

```python
"""请求体字节上限：FastAPI没有内置限制，在最外层ASGI先读满上限再交给应用。"""
import json
from collections.abc import Awaitable, Callable, MutableMapping
from typing import Any

Scope = MutableMapping[str, Any]
Message = MutableMapping[str, Any]
Receive = Callable[[], Awaitable[Message]]
Send = Callable[[Message], Awaitable[None]]
ASGIApp = Callable[[Scope, Receive, Send], Awaitable[None]]

# 最大合法请求是16条×2048码点。UTF-8直传每码点最多4字节；调用方若把非ASCII转义，
# 表情类字符要12字节，约393KB。上限取512KiB，合法请求不会被误拒。
MAX_BODY = 524_288
TOO_LARGE = json.dumps({"error": {"code": "BRIDGE_TOO_LARGE"}}).encode()


class BodyLimit:
    def __init__(self, app: ASGIApp, limit: int = MAX_BODY) -> None:
        self.app = app
        self.limit = limit

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http":
            await self.app(scope, receive, send)
            return
        declared = dict(scope["headers"]).get(b"content-length")
        if declared is not None and (not declared.isdigit() or int(declared) > self.limit):
            await self.reject(send)
            return
        # 分块传输没有Content-Length，或声明值偏小时，按实际收到的字节累计。
        parts: list[bytes] = []
        size = 0
        while True:
            message = await receive()
            if message["type"] == "http.disconnect":
                return
            part = message.get("body", b"")
            size += len(part)
            if size > self.limit:
                await self.reject(send)
                return
            parts.append(part)
            if not message.get("more_body", False):
                break
        body = b"".join(parts)
        delivered = False

        async def replay() -> Message:
            nonlocal delivered
            if not delivered:
                delivered = True
                return {"type": "http.request", "body": body, "more_body": False}
            return await receive()

        await self.app(scope, replay, send)

    @staticmethod
    async def reject(send: Send) -> None:
        await send({"type": "http.response.start", "status": 413,
                    "headers": [(b"content-type", b"application/json"),
                                (b"content-length", str(len(TOO_LARGE)).encode())]})
        await send({"type": "http.response.body", "body": TOO_LARGE})
```

```python
"""Milvus存取；集合结构、字段名与Node端vector-index.ts/projection.ts一致。"""
import asyncio
import json
import uuid
from collections.abc import Awaitable
from dataclasses import dataclass
from typing import Annotated, Any, TypeVar

import grpc
from pydantic import BaseModel, ConfigDict, Field, ValidationError
from pymilvus import AsyncMilvusClient, DataType, MilvusException

from ops_bridge.http_contracts import DIMENSION, SPACE

COLLECTION = "service_knowledge_" + SPACE
T = TypeVar("T")


class VectorStoreError(Exception):
    def __init__(self, code: str) -> None:
        super().__init__(code)
        self.code = code


@dataclass(frozen=True, slots=True)
class ChunkRow:
    """内部写入行；外部输入先经HTTP契约校验，再与编码结果组装成它。"""
    source_key: str
    group_id: uuid.UUID | str
    version: str
    start: int
    end: int
    vector: tuple[float, ...]


class Candidate(BaseModel):
    model_config = ConfigDict(extra="ignore", populate_by_name=True)
    source_key: str = Field(alias="sourceKey")
    version: str
    start: Annotated[int, Field(ge=0)]
    end: Annotated[int, Field(gt=0)]
    distance: float


def group_filter(group_id: uuid.UUID | None) -> str:
    # 只接受已解析的UUID，再按JSON转义拼进表达式；None表示调用方明确要求不过滤。
    return 'audience == "shared"' if group_id is None else 'audience in ["shared",' + json.dumps(str(group_id)) + ']'


def entity(row: ChunkRow) -> dict[str, Any]:
    if len(row.vector) != DIMENSION or row.end <= row.start:
        raise VectorStoreError("VECTOR_ROW")
    # 主键与Node端projection.ts相同：来源/内容版本/起点。
    return {"id": f"{row.source_key}/{row.version}/{row.start}", "sourceKey": row.source_key,
            "audience": str(row.group_id), "version": row.version, "start": row.start,
            "end": row.end, "vector": list(row.vector)}


class VectorStore:
    def __init__(self, client: AsyncMilvusClient, collection: str = COLLECTION,
                 deadline: float = 10) -> None:
        self._client = client
        self._collection = collection
        self._deadline = deadline
        self._ready = False

    async def _call(self, operation: Awaitable[T], code: str) -> T:
        # 实测连接不可达时客户端自己的timeout不生效，所以外面再套一层截止时间。
        try:
            async with asyncio.timeout(self._deadline):
                return await operation
        except TimeoutError:
            raise VectorStoreError("MILVUS_TIMEOUT") from None
        except MilvusException:
            raise VectorStoreError(code) from None
        except grpc.RpcError:
            # 实测Milvus进程停止时抛的是gRPC错误，不是MilvusException。
            raise VectorStoreError("MILVUS_UNAVAILABLE") from None

    async def ensure(self) -> None:
        schema = AsyncMilvusClient.create_schema(auto_id=False, enable_dynamic_field=True)
        schema.add_field("id", DataType.VARCHAR, is_primary=True, max_length=256)
        schema.add_field("vector", DataType.FLOAT_VECTOR, dim=DIMENSION)
        index = AsyncMilvusClient.prepare_index_params()
        index.add_index("vector", index_type="FLAT", index_name="vector_cosine", metric_type="COSINE")
        await self._call(self._client.create_collection(
            self._collection, schema=schema, index_params=index, consistency_level="Strong"),
            "MILVUS_SCHEMA")
        await self._call(self._client.load_collection(self._collection), "MILVUS_SCHEMA")

    async def upsert(self, rows: list[ChunkRow]) -> int:
        if not 1 <= len(rows) <= 16:
            raise VectorStoreError("VECTOR_ROW")
        data = [entity(row) for row in rows]
        if not self._ready:
            # 第一次写入前建集合并加载；启动时不连Milvus，避免它不可用时服务起不来。
            await self.ensure()
            self._ready = True
        result = await self._call(self._client.upsert(self._collection, data), "MILVUS_WRITE")
        return int(result["upsert_count"])

    async def search(self, vector: tuple[float, ...], group_id: uuid.UUID | None,
                     limit: int = 24) -> list[Candidate]:
        if len(vector) != DIMENSION or not 1 <= limit <= 24:
            raise VectorStoreError("VECTOR_QUERY")
        result = await self._call(self._client.search(
            self._collection, [list(vector)], filter=group_filter(group_id), limit=limit,
            output_fields=["sourceKey", "version", "start", "end"], anns_field="vector"),
            "MILVUS_SEARCH")
        try:
            return [Candidate.model_validate({**hit["entity"], "distance": hit["distance"]})
                    for hit in result[0]]
        except (ValidationError, KeyError, TypeError):
            raise VectorStoreError("MILVUS_CONTRACT") from None

    async def close(self) -> None:
        await self._client.close()


def milvus_store(uri: str = "http://127.0.0.1:19531") -> VectorStore:
    # 必须在事件循环里构造：AsyncMilvusClient创建时绑定当前循环。
    return VectorStore(AsyncMilvusClient(uri=uri, timeout=10))
```
