## 一、题库原题与原文答案

题库：《2026高德 Al agent 前端开发.pdf》第7页，第5题。

<details><summary>原文（只调整排版）</summary>

5. 什么是 Function Calling？前端在处理 Agent 的工具调用时需要注意什么？​
难度：★★★
考点：AI Agent 交互设计​
答案要点：
Function Calling 允许模型根据需求调用外部工具，前端负责展示调用过程并反馈执行结果。​
•
状态展示：需要设计专门的 UI 状态（如 思考中、正在查询地图、调用成功）。​
•
交互确认：对于敏感操作（如转账、删除），前端必须拦截并弹出确认框。
•
错误处理：当工具调用失败时，需要将错误信息反馈给模型，引导其重试或切换策略。
•
结果呈现：将工具返回的结构化数据（如 JSON）转化为可视化的图表或卡片。​
常见坑：
•
没处理好模型连续调用多个工具的串行/并行展示逻辑。​
•
工具返回数据过大，直接塞入 Context 导致 Token 溢出。​
追问：
•
如何在 UI 上优雅地展示 Agent 的思考链（CoT）？​

</details>

<details><summary>补充讲解与纠偏</summary>

前端负责可观察的工具进度和结果，不展示模型私有思维链。本项目工具只读，服务端决定身份和可见范围；敏感写操作即使有前端确认，也必须由服务端再次授权。工具失败不无限重试，沿用D64有限步骤。

</details>

## 二、项目与网络关联题

### 1. JSON Schema能替代数据权限吗？

<details><summary>完整答案与追问</summary>

不能。schema验证输入形状、类型和范围；当前用户能看哪些行必须由授权逻辑约束实际查询。本项目参数不含userId或groupId，身份来自认证上下文，班组和权限重新查询数据库。

</details>

### 2. 如何防止模型查询其他班组工单？

<details><summary>完整答案与追问</summary>

工具白名单和strict参数先拒绝不合法调用，然后查询where包含groupScope。跨组和不存在统一TOOL_NOT_FOUND。测试实际移除scope后出现跨组返回，恢复后拒绝，证明断言覆盖了关键边界。

</details>

### 3. 为什么不直接返回Prisma查询对象？

<details><summary>完整答案与追问</summary>

对象可能包含内部ID、联系人等不必要字段，并且结果过大。使用select及显式映射，只返回必要业务字段，列表、文本和UTF8总字节各有上限，截断状态明确。

</details>

### 4. 权限撤销何时生效？

<details><summary>完整答案与追问</summary>

下一次工具执行直接读取数据库，不等待缓存过期；正在进行的repeatable-read事务按已有快照完成，不承诺实时强停。后续回显历史还要复核资源归属，不能仅依赖创建会话时的权限。

</details>
