<details><summary>原题与答案原文</summary>

7. HTTP 状态码 204、301、302、304 分别代表什么含义？​
难度：★
考点：网络协议基础
答案要点：
状态码是服务器对请求处理结果的简短反馈。
•
204 No Content：请求成功，但响应报文不包含实体主体。​
•
301 Moved Permanently：永久重定向，搜索引擎会更新索引。​
•
302 Found：临时重定向，搜索引擎不会更新索引。​
•
304 Not Modified：协商缓存命中，表示资源未改变，直接使用本地缓存。​
常见坑：
•
混淆 301 和 302 对 SEO 的影响。​
•
不清楚 304 触发的前提条件（If-Modified-Since 等）。​
追问：
•
307 和 302 有什么区别？​
•
常见的 400 系列错误有哪些？​

</details>

HTTP 状态能描述请求结果。一个批量端点还需要查看各槽的业务结果，经 MCP 转换后继续保留这种区分。



## 项目面试与自检

### 1. 切换协议能否扩大客户管理员的权限？

MCP 转到同一业务服务，保留主体、用途及工单范围，拒绝结果一致。

### 2. 标准输出里夹入一行调试日志会怎样？

协议消息用标准输出，诊断写标准错误。核对请求配对和进程关闭。

### 3. 删除偏好会不会连同工单证据一起删除？

复核、反馈与处理记录属于工单，偏好有独立的用户范围和生命周期。
