## 一、知识点与推导

协议消息用标准输出，诊断写标准错误。核对请求配对和进程关闭。

先从已登录用户取得自己的 runId。用工具目录查看允许的参数，发起一次 MCP 调用，再改用另一客户身份请求同一 runId。把工具回执与直接访问 HTTP 的结果并列。

stdio 用换行划分 JSON-RPC 消息。标准输出上的普通日志会混进消息流，所以服务端诊断信息应写入标准错误。父进程通过 SDK 创建客户端，等待 connect 完成再开始请求。

把连接生命周期集中在 withTicketClient，正常返回和回调抛错都进入 finally。不带身份启动服务时允许验证目录，读取工单会收到明确的工具错误。

## 四、本章完整源码

**apps/server/src/mcp/client.ts**

```ts
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import type { Transport } from '@modelcontextprotocol/sdk/shared/transport.js';

// 同一个客户端入口适用于子进程和下一章的 HTTP 连接。
export async function withTicketClient<T>(transport: Transport, use: (client: Client) => Promise<T>) {
  const client = new Client({ name: 'ops-ticket-agent', version: '1.0.0' });
  try {
    await client.connect(transport);
    return await use(client);
  } finally { await client.close(); }
}
```

**apps/server/src/mcp/stdio.spec.ts**

```ts
import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';
import { withTicketClient } from './client.js';

function processTransport() {
  return new StdioClientTransport({ command: process.execPath, args: ['--import', 'tsx', 'src/mcp/stdio.ts'], env: {} });
}

describe('子进程协议', () => {
  it('从真实子进程取得服务名称和工具清单', async () => {
    await withTicketClient(processTransport(), async client => {
      expect(client.getServerVersion()?.name).toBe('ops-ticket');
      expect((await client.listTools()).tools.map(t => t.name)).toEqual(['ticket_summary']);
    });
  });

  it('未配置业务身份时返回工具错误', async () => {
    await withTicketClient(processTransport(), async client => {
      const result = await client.callTool({ name: 'ticket_summary', arguments: {} });
      expect(result.isError).toBe(true);
      expect(result.content).toEqual([{ type: 'text', text: 'TICKET_SESSION_REQUIRED' }]);
    });
  });
});
```

**apps/server/src/mcp/stdio.ts**

```ts
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { ticketServer, TicketToolFailure } from './server.js';

// 可以先连接并检查目录；业务凭据由下一章的启动配置提供。
const server = ticketServer(async () => { throw new TicketToolFailure('TICKET_SESSION_REQUIRED'); });
await server.connect(new StdioServerTransport());
```
