# D120 面试题　当前用户与场景权限

## 题库原题与原文答案

本地《2026电信前端AI工程师面试.pdf》，第 8 页。

<details><summary>原题与答案原文</summary>

2. 在电信业务场景下，AI 前端如何处理数据安全和隐私保护？​
难度：★★★
考点：数据安全、合规性
答案要点：
电信数据敏感度高，前端需配合后端建立多重防护体系。
•
脱敏处理：在发送 Prompt 前，通过正则或本地模型识别并拦截手机号、身份证等敏感信息。​
•
传输加密：全量使用 HTTPS，对敏感 Payload 进行二次加密。​
•
权限控制：严格校验会话 Token，防止越权访问历史对话。​
•
审计日志：记录用户的所有输入输出行为，用于事后溯源，但前端不存储敏感明文。
常见坑：
•
将敏感信息缓存在 localStorage 中被恶意脚本读取。​
•
在报错日志中泄露了用户的输入内容。
追问：
•
如果需要在前端实现本地脱敏，你会选择什么技术方案？

</details>

题库谈及脱敏与权限控制。脱敏帮助缩小已授权结果的暴露面；工单能否被读取仍要由服务端验证。



## 项目面试与自检

### 1. 客户管理员能查看全公司工单，能否因此批准发布？

读取、处理、复核和发布分别授权。审批注册和查看工单是客户管理员的两项权限。

### 2. 写操作丢回执时先问模型还是查持久记录？

查服务端回执，无法确认时保留待核对状态。

### 3. 一个工具成功能否掩盖另一个工具失败？

逐次记录工具状态，后续建议只能引用成功且仍有效的证据。
