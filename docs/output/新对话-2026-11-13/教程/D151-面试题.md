# D151 面试题　提供可发现的HTTP资源

## 题库原题与原文答案

本地《2024字节前端面试题（45题）.pdf》，第 12 页。

<details><summary>原题与答案原文</summary>

19. 什么是跨域？你通常如何解决跨域问题？​
跨域是指一个域的网页试图请求另一个域的资源。出于安全考虑，浏览器会实施同源策略，限制从一
个源加载的文档或脚本如何与另一个源的资源进行交互。
解决方案包括：
•
CORS（跨源资源共享）：在服务器上设置适当的HTTP头，如Access-Control-Allow-
Origin ，允许特定的外部域访问资源。
•
JSONP（仅限于GET请求）：利用<script> 标签的这种特性，可以绕过限制，但它不支持
POST、PUT和其他类型的HTTP请求。​
•
代理服务器：通过服务器端代理进行请求，服务器对外作为同源，对内可以访问其他域的资源。

</details>

题库解释浏览器同源策略。MCP 回环资源主动检查 Host 和 Origin，调用者还须单独完成 OAuth。



## 项目面试与自检

### 1. 资源没有出现在列表就足够安全吗？

发现与逐项读取均核对权限，缓存键包含可见范围和版本。

### 2. 切换协议能否扩大客户管理员的权限？

MCP 转到同一业务服务，保留主体、用途及工单范围，拒绝结果一致。

### 3. 工具能被客户端发现是否代表当前用户可执行？

描述只公开契约，调用时用真实主体重新授权并保留审计。
