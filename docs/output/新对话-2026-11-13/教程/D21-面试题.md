# D21 模拟面试：第三周

## 新版工单口述与自检

用第三周的测试矩阵口述四个身份，给出同一张工单对查看、验收、人工处理、知识审核四种动作的不同结果。

新版练习按[本日讲义](D21-第三周复盘.md)的操作与验收结果作答。

## 技术题及出处

以下题库保留来源中的场景，历史实验的数字仅对应原课程。

配套讲义：[D21：第三周复盘](D21-第三周复盘.md)。今天不引入新题，从 D15-D20 的面试题里挑出 8 道，按真实面试的方式练：先口述，再接追问，最后对照答案打分。

每道题后面的“答案在哪”指向原来的面试题文件或讲义，那里有原题出处、原文答案和完整的参考答案。

## 规则

1. 每题限时 3 分钟口述，不看资料。追问每个限时 1 分钟。
2. 每题都要包含一个你在这个项目里亲手做过的例子，最好带上一个测出来的数字或现象。
3. 这一周的题按“这一层要回答什么问题 → 我怎么实现的 → 漏了会怎样（反证实验）”的顺序讲。
4. 全部说完再对照答案，按末尾的评分表打分。

## 题单

### 第 1 题：你的系统是怎么做登录的？密码怎么存、令牌放在哪？

答案在哪：[D15 面试题](D15-面试题.md) 题 1、题 4、题 5；讲义 [D15](D15-登录替换x-user.md) 1.1-1.3。

追问：

1. 为什么不用 SHA-256？scrypt 的参数存在哪里，为什么要存？
2. “用户不存在”和“密码错误”的响应时间为什么要一样？你测出来差多少？
3. 令牌放 sessionStorage，有 XSS 时会怎样？你会怎样迁移到 HttpOnly Cookie？

### 第 2 题：JWT 被偷了或者签名密钥泄露了，怎么办？

答案在哪：[D15 面试题](D15-面试题.md) 题 3；讲义 [D15](D15-登录替换x-user.md) 推导题 1.3。

追问：

1. JWT 是加密的吗？载荷里能放什么、不能放什么？
2. 用户点了“退出登录”，偷到的令牌还能用吗？怎样才能让它立即失效？
3. 你们的系统里，令牌有效但用户已经被删除，会返回什么？

### 第 3 题：你们的权限系统是怎么设计的？

答案在哪：[D16 面试题](D16-面试题.md) 题 1、题 2；讲义 [D16](D16-角色与权限点.md) 1.1-1.3。

追问：

1. 权限点和角色，哪个写在代码里、哪个是数据？为什么？
2. 新接口忘了加权限声明会怎样？你是怎么保证不会漏的？
3. 权限为什么不放进令牌？每次查库的代价是什么？

### 第 4 题：什么是水平越权？你们怎么防的？

答案在哪：[D17 面试题](D17-面试题.md) 题 1、题 4；讲义 [D17](D17-行级数据权限.md) 1.2、1.3。

追问：

1. 别的班组的工单，为什么返回 404 而不是 403？
2. 批量接口、游标、原生 SQL 分别要注意什么？你测过哪些“换参数绕过”的情况？
3. 一个没有分组的新账号，在你们的系统里能看到什么？为什么这样设计？

### 第 5 题：数据隔离放在应用层还是用 PostgreSQL 的 RLS？

答案在哪：[D17 面试题](D17-面试题.md) 题 2。

追问：

1. RLS 在什么情况下会不生效？
2. 用 RLS 时，连接池会带来什么问题？`set_config` 的第三个参数是做什么的？
3. 你们为什么选了应用层？用什么弥补“忘了加”的风险？

### 第 6 题：操作审计你们是怎么做的？

答案在哪：[D18 面试题](D18-面试题.md) 题 3、题 4；讲义 [D18](D18-操作审计.md) 1.1-1.3。

追问：

1. 审计为什么要和业务写在同一个事务里？写在事务外你测到了什么？
2. 怎么保证审计不被修改？只在代码里不写 update 为什么不够？
3. 审计里记什么、不记什么？“被遗忘权”和只追加怎么调和？

### 第 7 题：手机号这类敏感字段你们怎么处理的？

答案在哪：[D19 面试题](D19-面试题.md) 题 1、题 3、题 4；讲义 [D19](D19-敏感字段脱敏.md) 1.2-1.4。

追问：

1. 脱敏为什么放在全局拦截器，而不是每个接口自己处理？
2. 日志里怎么会出现手机号？你是怎么发现的？
3. 掩码值被前端原样提交回来会怎样？你们怎么防的？

### 第 8 题：前端的权限是怎么做的？

答案在哪：[D20 面试题](D20-面试题.md) 题 1、题 3、题 4；讲义 [D20](D20-前端权限与审计时间线.md) 1.1-1.3。

3. 后端已经脱敏了，前端要不要再遮一下？
