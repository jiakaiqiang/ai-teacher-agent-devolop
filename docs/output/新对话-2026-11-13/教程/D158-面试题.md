# D158 面试题　汇总多轮稳定性与成本

## 题库原题与原文答案

本地《2026京东前端面试-大模型方向.pdf》，第 12 页。

<details><summary>原题与答案原文</summary>

2. 在 AI 项目中，你是如何定义和衡量“前端用户体验”的？有哪些具体的指标？​
难度：★★
考点：质量保障、指标体系
答案要点：
AI 应用的体验不仅看加载速度，更看交互的流畅度和反馈的及时性。​
•
核心指标：First Token Latency（首字响应时间）、Generation Speed（生成速度 chars/s）、
Request Success Rate​
•
交互指标：输入框响应延迟、长文本渲染是否掉帧、自动滚动触发的准确率
•
业务指标：用户点赞/点踩比率、对话完成率、Agent 任务执行成功率
•
监控手段：接入全链路埋点，记录模型返回的 trace_id 方便排查前端渲染异常​
常见坑：
•
只关注首屏加载时间，忽略了模型生成过程中的卡顿
•
缺乏对模型报错后的用户行为监控

</details>

体验指标可以从前端延展到完整诊断请求。本章的 P95 是后端诊断请求耗时，包含工具与模型时间。



## 项目面试与自检

### 1. 平均分相同，两组结果是否同样稳定？

按题比较跨轮一致性并报告方差、失败类型与成本。

### 2. 仅比较最终状态能抓到一次多余派单吗？

同时核对工具调用顺序、写事件数和最终状态。

### 3. 同一条模型文本正确但越权读日志，判定如何？

任务、权限和状态分别标注。任何越权动作均判该题失败。
