<details><summary>原题与答案原文</summary>

1. 如果让你从零搭建一个前端监控系统，你会如何设计它的架构？​
难度：★★★
考点：系统设计、全链路思维
答案要点：
前端监控系统应包含数据采集、数据上报、数据处理和可视化监控四个核心模块。
•
数据采集：通过 SDK 自动捕获 JS 错误、Promise 异常、资源加载失败、性能指标（Vitals）及用
户行为轨迹。
•
上报策略：采用 navigator.sendBeacon 保证页面卸载时也能成功上报，并支持批量上报与节流。​
•
数据处理：后端对原始日志进行清洗、脱敏，并利用 SourceMap 还原错误堆栈。​
•
告警体系：设置阈值告警，通过钉钉/邮件通知相关负责人，并提供多维度的看板展示。​
常见坑：
•
监控 SDK 自身报错导致业务页面崩溃。​
•
上报流量过大对业务服务器造成压力。
追问：
•
如何实现无痕埋点？
•
如何保证监控数据的准确性和不丢失？

</details>

监控需能引导后续行动。本章把同空间 Trace 和最终反馈变成复核队列，队列中的异常占比不能外推为总体故障率。



## 项目面试与自检

### 1. 为什么要单列模拟网关与真实模型？

二者能证明的范围不同，报告逐题列明来源与模型版本。

### 2. 只检查最终到了人工待办能否发现这个错误？

门禁校验触发人、事件顺序和状态。干净样本退出零，篡改样本退出非零。

### 3. 平均分相同，两组结果是否同样稳定？

按题比较跨轮一致性并报告方差、失败类型与成本。
