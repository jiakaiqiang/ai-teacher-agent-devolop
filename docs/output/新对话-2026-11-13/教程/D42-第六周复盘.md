### 1.1 两次累计样本形成一个窗口

练习输入为同一进程、同一固定路由/实例范围的样本 `{epoch, atMs, requests, errors}`，requests只含完成的普通HTTP，errors是其中5xx，不含aborted。采样器未来必须保证两个计数来自相同快照；本章不从Prometheus文本解析，也不自动提供epoch。

```text
窗口请求数 = 当前requests - 上次requests
窗口错误数 = 当前errors - 上次errors
窗口错误率 = 窗口错误数 / 窗口请求数
```

本练习策略：有效窗口至少20个请求；严格超过5%算坏窗口；连续3个有效坏窗口进入firing；相邻样本间隔最多120秒。常规示例间隔60秒，但函数不要求固定60秒，因此“3个窗口”不等于“持续3分钟”，也不等价于Prometheus的for时长。

**推导题**：历史10000次成功后，当前100次有10次错误，用累计比率会怎样？

<details><summary>答案</summary>

窗口错误率10%，累计比率约0.099%，会把当前故障稀释成正常。反证A直接验证这个差别，计算阈值必须保持同一窗口。

</details>

### 1.2 未知、预热、样本不足都不是健康

| 输入情况 | 返回 | 下一窗口 |
|---|---|---|
| 第一个有效样本 | warming | 保存基线，不算比率 |
| epoch改变、计数下降、间隔过长 | warming | 换基线，连续数归零 |
| 缺测、非法值、乱序、增量错误大于请求 | unknown | 丢弃基线，下次先预热 |
| 请求不足20，含0请求 | insufficient | 保留本次基线，连续数归零 |
| 足够样本且比率≤5% | ok | 连续数归零 |
| 足够样本且>5% | pending/firing | 连续数增加，上限3 |

bad→bad→低样本→bad只能回到pending。unknown/insufficient会停止本函数的firing状态，这不代表事故已经恢复；真正通知系统要把“观测丢失”和“恢复”分开处理，不能照抄status变化自动发恢复消息。本章无通知、持久状态、多路由状态仓库。

**推导题**：重启后请求数已经大于旧数，为什么还要epoch？

<details><summary>答案</summary>

只检查下降会把两个进程生命周期拼成一个窗口；显式epoch让新进程强制重新预热。epoch来自采集侧可靠的进程标识，不应是每次抓取随机生成的字符串。

</details>

### 1.3 练习阈值与SLO不同

SLI是怎么测，SLO是统计范围与目标，SLA还包含对外约定和未达标后果。请求失败预算与时间中断预算是不同分母。本文5%/20次/3窗口是教学规则，不是本工单系统的正式目标，也不是D32工单处理时限的替代品。

更完整的SLO告警还需要长短窗口、燃烧率、采集失败规则、抑制与通知处置；参考[Google SRE的SLO告警章节](https://sre.google/workbook/alerting-on-slos/)与[Prometheus告警规则](https://prometheus.io/docs/prometheus/latest/configuration/alerting_rules/)。本章只练确定性状态转换。

**推导题**：错误率很低能证明服务正常吗？

<details><summary>答案</summary>

不能，可能没有流量、抓取失败、关键链路没覆盖，或请求都卡住尚未完成。需要同时看流量、延迟、积压与可达性；选择的SLI必须对应用户真正关心的结果。

</details>

**apps/server/src/operations/error-window.ts**

```ts
// D42 变式：只评估输入样本，不抓取网络、不发通知、不自动改业务状态。
export interface CounterSample {
  readonly epoch: string; // 同一进程生命周期标识，重启后必须变化
  readonly atMs: number;
  readonly requests: number; // 同一固定范围内已完成的普通 HTTP
  readonly errors: number; // 其中的 5xx；不包含 aborted
}
export interface WindowPolicy {
  readonly minRequests: number;
  readonly maxErrorRatio: number;
  readonly requiredWindows: number;
  readonly maxGapMs: number;
}
export interface WindowState {
  readonly previous: CounterSample | null;
  readonly consecutive: number;
  readonly status: 'warming' | 'unknown' | 'insufficient' | 'ok' | 'pending' | 'firing';
  readonly reason: string;
  readonly requests: number | null;
  readonly errors: number | null;
  readonly ratio: number | null;
}
export const PRACTICE_POLICY: WindowPolicy = {
  minRequests: 20, maxErrorRatio: 0.05, requiredWindows: 3, maxGapMs: 120_000,
};
const natural = (value: number) => Number.isSafeInteger(value) && value >= 0;

export function evaluateErrorWindow(
  state: WindowState | null, sample: CounterSample | null, policy: WindowPolicy = PRACTICE_POLICY,
): WindowState {
  if (!natural(policy.minRequests) || policy.minRequests < 1 || !natural(policy.requiredWindows) || policy.requiredWindows < 1
    || !natural(policy.maxGapMs) || policy.maxGapMs < 1 || !Number.isFinite(policy.maxErrorRatio)
    || policy.maxErrorRatio < 0 || policy.maxErrorRatio > 1) throw new Error('INVALID_WINDOW_POLICY');
  const reset = (status: WindowState['status'], reason: string, previous: CounterSample | null): WindowState => ({
    previous: previous ? { ...previous } : null, consecutive: 0, status, reason, requests: null, errors: null, ratio: null,
  });
  if (!sample) return reset('unknown', 'missing-sample', null);
  if (!sample.epoch || !natural(sample.atMs) || !natural(sample.requests) || !natural(sample.errors)
    || sample.errors > sample.requests) return reset('unknown', 'invalid-sample', null);
  const previous = state?.previous;
  if (!previous) return reset('warming', 'first-sample', sample);
  if (sample.atMs <= previous.atMs) return reset('unknown', 'out-of-order', null);
  if (sample.epoch !== previous.epoch) return reset('warming', 'epoch-changed', sample);
  if (sample.atMs - previous.atMs > policy.maxGapMs) return reset('warming', 'gap-too-long', sample);
  if (sample.requests < previous.requests || sample.errors < previous.errors) return reset('warming', 'counter-reset', sample);
  const requests = sample.requests - previous.requests;
  const errors = sample.errors - previous.errors;
  if (errors > requests) return reset('unknown', 'inconsistent-delta', null);
  const measured = { previous: { ...sample }, requests, errors };
  // 没有足够样本时打断连续性，既不是健康，也不能跨空窗凑连续异常。
  if (requests < policy.minRequests) return { ...measured, consecutive: 0, status: 'insufficient', reason: 'low-traffic', ratio: null };
  const ratio = errors / requests;
  if (ratio <= policy.maxErrorRatio) return { ...measured, ratio, consecutive: 0, status: 'ok', reason: 'within-threshold' };
  const consecutive = Math.min((state?.consecutive ?? 0) + 1, policy.requiredWindows);
  return { ...measured, ratio, consecutive, status: consecutive >= policy.requiredWindows ? 'firing' : 'pending', reason: 'over-threshold' };
}
```

**apps/server/src/operations/error-window.spec.ts**

```ts
import { appendFileSync } from 'node:fs';
import { evaluateErrorWindow, PRACTICE_POLICY, type CounterSample, type WindowState } from './error-window.js';

const point = (atMs: number, requests: number, errors: number, epoch = 'process-a'): CounterSample => ({ atMs, requests, errors, epoch });
const first = () => evaluateErrorWindow(null, point(0, 0, 0));
const report = (data: object) => {
  if (process.env.D42_EVIDENCE_FILE) appendFileSync(process.env.D42_EVIDENCE_FILE, JSON.stringify(data) + '\n');
};
describe('错误率窗口变式（D42）', () => {
  it('首个样本只建立基线', () => {
    expect(evaluateErrorWindow(null, point(0, 1000, 10))).toMatchObject({ status: 'warming', ratio: null, consecutive: 0 });
  });
  it('使用窗口增量，不能被历史成功稀释', () => {
    const initial = evaluateErrorWindow(null, point(0, 10_000, 0));
    const state = evaluateErrorWindow(initial, point(60_000, 10_100, 10));
    expect(state).toMatchObject({ status: 'pending', requests: 100, errors: 10, ratio: 0.1 });
    report({ case: 'window-delta', status: state.status, requests: state.requests, errors: state.errors, ratio: state.ratio });
  });
  it('恰好等于 5% 不算超过阈值', () => {
    expect(evaluateErrorWindow(first(), point(60_000, 20, 1))).toMatchObject({ status: 'ok', ratio: 0.05, consecutive: 0 });
  });
  it('三个连续有效坏窗口才触发，计数封顶', () => {
    let state = first(); const statuses: string[] = [];
    for (let index = 1; index <= 4; index++) {
      state = evaluateErrorWindow(state, point(index * 60_000, index * 20, index * 2)); statuses.push(state.status);
    }
    expect(statuses).toEqual(['pending', 'pending', 'firing', 'firing']);
    expect(state.consecutive).toBe(3);
    report({ case: 'consecutive-windows', statuses, consecutive: state.consecutive });
  });
  it('一个健康窗口打断连续异常', () => {
    const bad = evaluateErrorWindow(first(), point(60_000, 20, 2));
    const good = evaluateErrorWindow(bad, point(120_000, 40, 2));
    const again = evaluateErrorWindow(good, point(180_000, 60, 4));
    expect(good.status).toBe('ok'); expect(again.consecutive).toBe(1);
  });
  it('低样本窗口必须清零连续计数', () => {
    let state = evaluateErrorWindow(first(), point(60_000, 20, 2));
    state = evaluateErrorWindow(state, point(120_000, 40, 4));
    state = evaluateErrorWindow(state, point(180_000, 41, 5));
    expect(state).toMatchObject({ status: 'insufficient', ratio: null });
    state = evaluateErrorWindow(state, point(240_000, 61, 7));
    expect(state.status).toBe('pending'); expect(state.consecutive).toBe(1);
    report({ case: 'low-traffic-break', status: state.status, consecutive: state.consecutive });
  });
  it('新进程计数更大也必须重新建立基线', () => {
    const state = evaluateErrorWindow(first(), point(60_000, 100, 10, 'process-b'));
    expect(state).toMatchObject({ status: 'warming', reason: 'epoch-changed', consecutive: 0 });
  });
  it('同进程计数下降按重置处理', () => {
    const initial = evaluateErrorWindow(null, point(0, 100, 10));
    expect(evaluateErrorWindow(initial, point(60_000, 5, 1))).toMatchObject({ status: 'warming', reason: 'counter-reset' });
  });
  it('超长间隔重新预热，乱序和重复时间视为未知', () => {
    expect(evaluateErrorWindow(first(), point(120_001, 20, 2)).reason).toBe('gap-too-long');
    const initial = evaluateErrorWindow(null, point(10, 0, 0));
    for (const time of [9, 10]) expect(evaluateErrorWindow(initial, point(time, 20, 2))).toMatchObject({ status: 'unknown', previous: null });
  });
  it('不可信数值与不一致增量不能算成健康', () => {
    for (const sample of [point(1, NaN, 0), point(1, -1, 0), point(1, 1, 2), point(1, 0.5, 0), point(1, 1, 0, '')]) {
      expect(evaluateErrorWindow(first(), sample).status).toBe('unknown');
    }
    const initial = evaluateErrorWindow(null, point(0, 100, 0));
    expect(evaluateErrorWindow(initial, point(60_000, 101, 2)).reason).toBe('inconsistent-delta');
    expect(() => evaluateErrorWindow(null, null, { ...PRACTICE_POLICY, minRequests: 0 })).toThrow('INVALID_WINDOW_POLICY');
  });
  it('零请求是样本不足，缺测打断后从预热重新开始', () => {
    expect(evaluateErrorWindow(first(), point(60_000, 0, 0))).toMatchObject({ status: 'insufficient', ratio: null });
    const missing = evaluateErrorWindow(first(), null);
    expect(missing).toMatchObject({ status: 'unknown', reason: 'missing-sample', previous: null });
    expect(evaluateErrorWindow(missing, point(120_000, 20, 2)).status).toBe('warming');
    report({ case: 'missing-window', status: missing.status, reason: missing.reason });
  });
  it('不修改旧状态或样本，外部修改样本不改变已保存基线', () => {
    const sample = point(0, 0, 0); const state = evaluateErrorWindow(null, sample);
    const before = JSON.stringify(state);
    evaluateErrorWindow(Object.freeze(state) as WindowState, Object.freeze(point(60_000, 20, 2)));
    expect(JSON.stringify(state)).toBe(before);
    Object.assign(sample, { requests: 999 });
    expect(state.previous?.requests).toBe(0);
  });
});
```
