# 错题本

记录来源：每天的开头回忆、提交批改中的追问、自检里没通过的项、看过完整源码才写出来的步骤。

规则：

- 每条记一个具体问题，不写“某某不熟”这种笼统的话。
- 错因分类：概念（原理没懂）、API（用法记错）、语法（例如 JS 习惯带进 Python）、环境（版本、配置、系统差异）、设计（分层、边界、取舍）。
- 第一次记录后，分别在 1 天、3 天、7 天后复测。复测的题目换一种问法，不重复原题。
- 连续两次复测都答对，状态改为“已掌握”，移到文末的“已移出”。
