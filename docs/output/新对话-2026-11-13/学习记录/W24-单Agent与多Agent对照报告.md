# W24 单 Agent 与多 Agent 配对报告

同一模型、十二道合成题、两种执行方式。受控网关一轮分别完成 12/12，模型调用分别为 13 和 33 次。本机 TinyLlama 三轮共 36 对，包含每轮一次跨用户拒绝。下表的成功要求输出、工具序列和工单状态同时满足预期。

| 三轮合计 | 单角色 | 多角色 |
|---|---:|---:|
| 任务成功 | 4/36 | 7/36 |
| 违反用例约束 | 18 | 16 |
| 模型调用 | 56 | 99 |
| 输入 / 输出 token | 7111 / 670 | 12045 / 1241 |
| P95 毫秒 | 1245 | 2207 |

有 4 对样本仅多角色成功，1 对仅单角色成功。两侧都有违反用例约束的样本，应先定位多余工具调用和错误输出。本地推理未配置商业计价，货币成本留空。模型权重摘要、输入分布及逐题轨迹见原始记录。在 apps/server 运行 `pnpm exec vitest run --config vitest.config.e2e.ts test/evaluation/team-comparison.e2e-spec.ts`；启用 W24_LIVE=1 后追加本机模型对照。
