## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：汇总安全、部署、回滚、Eval、Trace 和已知限制。先写失败测试，再完成最短用户链路；checkpoint 是一次任务有确定终态、owner 和 traceId。
2. **v2 关键加层**：用目标岗位矩阵绑定每项能力到真实证据。复用 v1 合同；checkpoint 是正常、边界和权限/并发测试可重复。
3. **v3 生产约束**：完成可复现演示、故障恢复、量化来源和 MCP/RAG/Runtime 成熟度边界。补预算、审计、恢复、Eval 或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day89 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day89。实际命令和输出写入 evidence/day89/。

## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. 教学模拟：Electron 桌面 Agent 准备发布给 10 个企业租户；PRR 发现一个窗口关闭 sandbox、两个 IPC 无参数校验，自动更新回滚从未演练。请按五段式给出安全与发布证据，阻断上线、修复隔离和 IPC、验证攻击/回滚，并演进生产就绪治理。
   依据：[Electron Security](https://www.electronjs.org/docs/latest/tutorial/security)
2. 教学模拟：Trace 中记录了用户 Prompt、API key 片段和文件绝对路径；已有 90 天、约 2TB 历史数据，直接删除会破坏审计。请按五段式定位敏感字段与访问证据，止损采集、修复脱敏与密钥、验证审计可用，并演进数据保留策略。
   依据：[OWASP LLM Top 10](https://genai.owasp.org/llm-top-10/)
知识映射：Day 89：Production Readiness、安全、部署、回滚、脱敏和已知限制。
