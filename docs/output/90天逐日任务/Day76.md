## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：展示审批对象和允许/拒绝按钮。先写失败测试，再完成最短用户链路；checkpoint 是一次调用或 Run 有确定终态和 traceId。
2. **v2 关键加层**：增加风险、作用域、diff、副作用、超时和 Session 标识。复用 v1 合同；checkpoint 是正常、边界和权限/重放测试可重复。
3. **v3 生产约束**：加入双击防护、过期态、切 Session 隔离、撤销边界和无障碍状态。补取消、超时、审计、恢复或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day76 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day76。实际命令和输出写入 evidence/day76/。
