## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：闭卷解释三条链路边界并跑正常基线。先写失败测试，再完成最短用户链路；checkpoint 是一次调用或 Run 有确定终态和 traceId。
2. **v2 关键加层**：独立修复一个随机故障并完成定向回归。复用 v1 合同；checkpoint 是正常、边界和权限/重放测试可重复。
3. **v3 生产约束**：组合断 MCP、拒绝审批、Embedding 失败完成隔离、恢复和评分。补取消、超时、审计、恢复或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day80 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day80。实际命令和输出写入 evidence/day80/。

## 必做测试与两个反证

- 测试范围：MCP 断连、审批拒绝/过期、Embedding 失败、越权副作用、引用正确性和恢复；至少覆盖正常、边界、权限或并发/重放、恢复中的三类。
