## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：保存一次 Session 的版本化 Trace 并离线重放。先写失败测试，再完成最短用户链路；checkpoint 是一次任务有确定终态、owner 和 traceId。
2. **v2 关键加层**：绑定 Prompt/Model/Tool Policy、数据集和随机种子做 A/B。复用 v1 合同；checkpoint 是正常、边界和权限/并发测试可重复。
3. **v3 生产约束**：加入敏感字段脱敏、缺失依赖检测、差异归因和不可复现标记。补预算、审计、恢复、Eval 或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day86 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day86。实际命令和输出写入 evidence/day86/。

## 必做测试与两个反证

- 测试范围：确定性重放、版本缺失、敏感字段、A/B 样本配对、工具漂移和差异报告；至少覆盖正常、边界、权限或并发/重放、恢复中的三类。
- 反证 1：不固定工具策略版本后重放同一 Session，差异报告必须标记不可比较。记录复现步骤、可观察信号、恢复动作和恢复后测试。
- 反证 2：关闭脱敏保存用户密钥，安全测试必须失败并阻止 Trace 入库。记录复现步骤、可观察信号、恢复动作和恢复后测试。
