## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

   依据：[S19 Vue reactivity](https://vuejs.org/guide/extras/reactivity-in-depth.html)
2. 5,000 个点每次都被深层 reactive 代理并全量重建 option，流式更新时 FPS 降到 18。请用 Vue 依赖追踪、Performance flame chart 和组件更新次数找出无效依赖；先缩短窗口止损，再用稳定 key、浅层状态与增量更新修复，比较 10 分钟 CPU、内存和帧率基线。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S19 Vue reactivity](https://vuejs.org/guide/extras/reactivity-in-depth.html)
