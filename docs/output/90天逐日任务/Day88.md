## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：注入单一模型/Runtime 5xx 并验证降级。先写失败测试，再完成最短用户链路；checkpoint 是一次任务有确定终态、owner 和 traceId。
2. **v2 关键加层**：增加 Redis/Postgres 中断、进程崩溃和取消竞态。复用 v1 合同；checkpoint 是正常、边界和权限/并发测试可重复。
3. **v3 生产约束**：组合故障测量 RTO/RPO、爆炸半径、数据一致性和防复发门禁。补预算、审计、恢复、Eval 或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day88 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day88。实际命令和输出写入 evidence/day88/。

   依据：[LangGraph Persistence](https://docs.langchain.com/oss/python/langgraph/persistence)
