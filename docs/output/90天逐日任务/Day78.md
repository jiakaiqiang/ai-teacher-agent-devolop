## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：人工标注 30 条 query/相关文档黄金集。先写失败测试，再完成最短用户链路；checkpoint 是一次调用或 Run 有确定终态和 traceId。
2. **v2 关键加层**：运行关键词检索并计算 Recall@5、MRR。复用 v1 合同；checkpoint 是正常、边界和权限/重放测试可重复。
3. **v3 生产约束**：加入答案/引用正确性、失败分类、版本报告和门禁阈值。补取消、超时、审计、恢复或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day78 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day78。实际命令和输出写入 evidence/day78/。

## 真实项目情境题（联网更新 2026-07-13）
