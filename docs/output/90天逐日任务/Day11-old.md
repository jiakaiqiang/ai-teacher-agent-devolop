## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. `getMetrics` Tool 接收模型生成的 `limit=-1`，Registry 未校验便查询 DB，Tool Run 卡住 30 秒。请用 ToolCall 参数、Schema 结果、SQL 和超时日志定位；先下线该 Tool 止损，再实现输入 Schema、超时和错误裁剪，并用非法/超大参数集验证。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S1 Aime](https://jobs.bytedance.com/experienced/position/7650035429911824693/detail)
2. 某只读 Tool 返回 20MB 原始记录，其中包含跨租户字段，随后被塞进模型 Context。请用授权决策、结果大小、tenantId 与审计日志定位；先禁止大结果并清空缓存止损，再做最小权限、字段白名单、分页/摘要和调用审计，验证跨租户与超额结果均被拒。回答必须按“定位证据 -> 临时止损 -> 根因修复 -> 回归验证”组织。
   依据：[S30 OWASP GenAI](https://genai.owasp.org/)
