## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：闭卷完成 C4、时序、Threat Model、SLO 和 Eval 因果说明。先写失败测试，再完成最短用户链路；checkpoint 是一次任务有确定终态、owner 和 traceId。
2. **v2 关键加层**：独立实现一个随机合同变更并通过兼容测试。复用 v1 合同；checkpoint 是正常、边界和权限/并发测试可重复。
3. **v3 生产约束**：处理随机故障、完成恢复/回滚、单多 Agent ROI 说明和最终项目讲述。补预算、审计、恢复、Eval 或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day90 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day90。实际命令和输出写入 evidence/day90/。

## 必做测试与两个反证

- 测试范围：架构、独立编码、权限、安全、Eval、Trace/Replay、SLO、随机故障和发布决策；至少覆盖正常、边界、权限或并发/重放、恢复中的三类。
