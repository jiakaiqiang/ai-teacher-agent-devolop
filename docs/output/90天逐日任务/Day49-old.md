## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. 模拟情境：文档更新后 8% Citation 指向已删除 chunk，用户点击得到 404。请从 answerId、sourceId、chunkId、version 和检索 Trace 定位，先隐藏失效引用并提示重新生成，再修复不可变版本引用和删除策略，验证引用始终回溯到原文版本。
   依据：[pgvector](https://github.com/pgvector/pgvector)
2. 模拟情境：某租户没有任何授权证据，但模型仍生成确定性答案并伪造两个引用编号。请检查 retrieval count、context assembly 和生成输出，先启用无证据拒答，再修复 grounding gate 与 Citation 校验，使用空召回、越权和伪造引用集验证拒答率与误拒率。
   依据：[OWASP LLM Top 10](https://genai.owasp.org/llm-top-10/)
知识映射：对应 context assembly、citation lineage、grounding 和拒答。
