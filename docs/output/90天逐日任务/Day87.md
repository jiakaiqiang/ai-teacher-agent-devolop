## v1 -> v2 -> v3 执行步骤

1. **v1 最小闭环**：采集成功率、P50/P95/P99、token 和成本基线。先写失败测试，再完成最短用户链路；checkpoint 是一次任务有确定终态、owner 和 traceId。
2. **v2 关键加层**：按 Runtime/角色/任务类型建立 SLI 与 error budget。复用 v1 合同；checkpoint 是正常、边界和权限/并发测试可重复。
3. **v3 生产约束**：增加告警 owner、抑制/聚合、容量阈值和可执行 Runbook。补预算、审计、恢复、Eval 或发布门禁；checkpoint 是故障后无静默成功、越权和重复副作用。
4. **运行命令**：在 D:\demo\ai-techer\p2-agent-workbench 执行 uv run pytest tests/day87 -q；涉及前端时再执行 pnpm --dir frontend test -- --run day87。实际命令和输出写入 evidence/day87/。
