## 真实项目情境题（联网更新 2026-07-13）

> 以下是依据当前中国岗位职责和官方技术机制构造的教学模拟，不代表来源企业真实发生过相同事故。题目中的规模和指标是练习约束，不是本项目已经取得的生产数据。

1. 教学模拟：同名 MCP Tool 在 18 个租户下绑定不同数据域，缓存键只含 tool_name；出现 11 次跨租户结果复用。请按五段式给出 capability binding、tenant/session 和 cache span 证据，立刻清缓存隔离，修复授权键、验证越权攻击，并演进统一权限治理。
   依据：[MCP Spec 2025-06-18](https://modelcontextprotocol.io/specification/2025-06-18)
2. 教学模拟：高风险 shell 工具要求批准，但审计记录缺少批准人、scope 和原始参数；一周 9 万次调用中有 1,200 条无法追责。请按五段式回答如何保全证据、暂停高风险调用、修复审计合同、验证全链路，并演进不可抵赖审计。
   依据：[OWASP LLM Top 10](https://genai.owasp.org/llm-top-10/)
知识映射：Day 74：Capability binding、租户/会话隔离与审计。
