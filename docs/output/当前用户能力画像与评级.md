# 当前用户能力画像与评级

## 1. 一句话画像

**正在转型 AI 前端的中高级 Vue 前端工程师，偏企业应用工程化、性能优化、低代码与可视化；熟练使用 Codex、Claude Code 辅助交付，正在探索多 Agent 协同，后端能力刚起步。长期目标依次为 AI 前端、AI 全栈、AI Agent 工程师。**

不应包装成：成熟全栈工程师、AI 前端专家、前端架构师或多 Agent 平台专家。

## 2. 画像构成

### 核心身份：企业级 Vue 前端

- 有约 7 年前端经历，覆盖企业门户、数据安全、运维系统、智慧工厂、机器人平台。
- 能承担中后台系统、组件抽离、Vue 迁移、Webpack 优化、ECharts/Three.js、uni-app 等交付任务。
- 有前端组长和 0-1 项目经历，但团队规模、治理方法和质量结果仍需证据。

### 特色能力：工程提效与平台化

- 做过私有 npm 服务、组件库、多语言 Loader、PEG.js 代码生成器、低代码 3D 平台和插件化 SDK。
- 相比普通业务前端，更愿意将重复工作沉淀为工具、平台或公共能力。
- 这是最值得建立的个人技术标签，比泛泛写“熟练各种框架”更有区分度。

### 新增优势：AI 辅助研发

- 熟练使用 Codex、Claude Code 完成需求拆解、编码、重构、测试和文档，可视为较强的 AI 工具应用能力。
- 价值在于利用 AI 放大已有前端经验，而不是用 AI 掩盖基础不足。
- 目前缺少接受率、人工修改率、测试通过率、缺陷率、节省时间等数据，尚不能证明成熟的 AI 工程方法论。

### 探索方向：多 Agent 协同

- 正在开发多 Agent 协同，说明具备任务分解、并行协作和工程自动化意识。
- 当前仍是开发/实践阶段。只有完成任务依赖、上下文隔离、成果交接、冲突处理、质量门禁和指标评估后，才能写成正式项目能力。

### 明确短板：后端刚起步

- 现有 Node.js 经验主要是工具和前端工程服务，不等于成熟后端经验。
- API、数据库、鉴权、数据一致性、日志、测试、部署、监控和故障处理尚在学习阶段。
- 当前可以描述为“借助 AI 完成简单全栈任务”，不能描述为“具备独立全栈架构和生产交付能力”。

## 4. 综合评级

### 技术能力评级：64/100，B 级

定义：能够独立交付复杂前端项目，具备部分平台化和工程治理能力；距离稳定的高级前端还差基础深度、质量体系、架构证据和项目复盘。

### 简历证明力：52/100，C 级

能力本身强于简历表现。当前简历的错字、重复、宽泛的“熟练掌握”和缺少测量口径，会让面试官低估真实能力或怀疑数据可信度。

### 职级判断

- 当前稳妥职级：**中高级前端工程师**。
- 条件合适时可面试：**高级 Vue 前端工程师**。
- 暂不建议直接定位：前端架构师、AI 前端专家、全栈高级工程师。

## 6. 优势与风险

### 主要优势

1. 不是纯页面开发，具备迁移、构建、组件、工具和平台化经验。
2. 项目领域丰富，能处理企业系统、数据可视化、跨端和 3D 场景。
3. 有把重复劳动工具化的倾向，适合工程效能、低代码和 AI Coding 方向。
4. AI 工具使用建立在多年开发经验上，比完全依赖提示词的初级使用者更有价值。

### 主要风险

1. 技能面过宽，但“源码、Three.js、微前端、性能、AI、全栈”都缺少足够深证据。
2. 可能形成 AI 工具依赖：能生成代码，但无法独立判断后端、安全或架构错误。
3. 多 Agent 仍在开发，如果没有指标和演示，容易被认为只是概念项目。
4. 后端刚起步，若写“全栈”会立即触发数据库、事务、鉴权、幂等、部署和故障追问。
5. 测试、安全、监控、CI/CD 和工程治理是高级岗位最明显的缺口。

## 7. 推荐发展路线

### 0-4 个月：达到 AI 前端求职门槛

- 用现有 Vue 与工程化能力作为底座，补 JavaScript、浏览器、TypeScript、测试和安全。
- 完成流式交互、取消重试、Markdown、RAG 引用、工具调用 UI 和 AI 指标。
- 交付一个可部署、可测试、可量化的 AI 前端作品，将专项能力从 50 分提升到 70 分。

### 4-12 个月：成长为 AI 全栈工程师

- 系统学习 Node.js 服务、API、数据库、鉴权、缓存、队列、测试、Docker 和部署。
- 将 AI 前端作品升级为具备 RAG、模型适配、权限、数据、观测和成本治理的完整平台。
- 达到能独立判断 AI 生成后端代码正确性的程度，专项评审达到 70 分后再使用“AI 全栈”标签。

### 12-24 个月：成长为 AI Agent 工程师

- 深入 Agent 循环、Function Calling、MCP、工作流 DAG、记忆、评测、Trace、安全和人工接管。
- 将当前多 Agent 探索项目建设为可评测的软件任务执行平台。
- 用任务成功率、人工修改率、缺陷率、耗时和成本证明多 Agent 的收益，专项评审达到 75 分。

## 8. 最终评级结论

当前最准确的市场标签是：

> **正在转型 AI 前端的中高级 Vue 前端工程师，熟练使用 Codex、Claude Code 进行 AI 辅助研发，正在开发多 Agent 协同工作流，后端能力处于起步阶段；目标依次为 AI 前端、AI 全栈、AI Agent 工程师。**

整体评级 **B，64/100**。核心前端能力接近高级，但证据链和质量体系尚未达到稳定高级；AI Coding 是加分项，多 Agent 是潜力项，后端目前只是学习项。
