# AI Teacher Agent Development Curriculum

面向高级 Vue 前端向 AI 前端、AI 应用全栈和 Agent 应用工程师转型的 90 天项目制课程。

## 路线

- Day 1-20：AI 前端架构、流式交互、Agent 事件、工具与审批 UI。
- Day 21-60：NestJS、FastAPI、PostgreSQL/pgvector、Redis、RAG、Eval、部署与可观测性。
- Day 61-90：从零构建 `p2-agent-workbench`，使用本机 Codex CLI / Claude Code CLI 完成轻量多 Agent 协同、MCP、Human Runtime、动态委派和生产治理。
